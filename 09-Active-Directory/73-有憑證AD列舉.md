## 學習目標

- 理解有憑證列舉與無憑證列舉的差異與延伸深度。
- 用 CrackMapExec（CME/NetExec）列舉使用者、群組、已登入帳號、共用資料夾。
- 用 SMBMap 列出共用資料夾權限並遞迴列目錄。
- 用 rpcclient 進行已驗證的 RPC 查詢。
- 從輸出中識別高價值目標（高權群組成員、已登入的特權帳號）。

---

## 理論基礎

```text
有憑證列舉的前提：
  至少需具備以下其中之一：
  → 有效網域帳號的明文密碼
  → 有效網域帳號的 NTLM hash
  → 已加域主機上的 SYSTEM 存取權限（電腦帳號可代替域帳號）

有憑證後可查詢的資訊（vs. 無憑證大幅增加）：
  使用者屬性（badPwdCount, memberOf, description 等）
  群組成員資格與巢狀群組
  GPO（群組原則物件）內容
  ACL / ACE（存取控制清單）
  信任關係（Trusts）
  已登入使用者會話（loggedon-users）
  SMB 共用資料夾及其內容

主要工具（Linux 端）：
  CrackMapExec / NetExec → SMB 協定列舉（使用者/群組/共用/會話）
  SMBMap                  → 共用資料夾權限 + 遞迴列目錄
  rpcclient               → MS-RPC 精細查詢
  ldapsearch / windapsearch → LDAP 屬性查詢
  BloodHound / bloodhound-python → 圖形化 ACL 路徑分析
```

## 工具一：CrackMapExec（CME / NetExec）

### 理論

```text
CME 是以 Impacket 和 PowerSploit 為基礎的多協定攻擊瑞士刀。
支援協定：SMB / MSSQL / SSH / WinRM
現已更名為 NetExec（nxc），語法幾乎相同。

關鍵旗標（SMB 協定）：
  -u  → 使用者名稱
  -p  → 密碼
  -H  → NTLM hash（Pass-the-Hash）
  -k  → Kerberos 認證（從 ccache 檔案）
  -d  → 網域名稱
  --users         → 列舉網域使用者（含 badPwdCount）
  --groups        → 列舉網域群組（含成員數）
  --loggedon-users→ 列舉目標主機上已登入的使用者
  --shares        → 列舉共用資料夾與權限
  -M spider_plus  → 爬取所有可讀共用資料夾並輸出 JSON

(Pwn3d!) 標記 = 當前帳號是該主機的本地管理員
```

### 列舉網域使用者

```bash
sudo crackmapexec smb 172.16.5.5 -u forend -p Klmcargo2 --users
# smb 172.16.5.5     → 目標 DC 的 IP（持有所有 AD 資料庫）
# -u forend          → 低權網域帳號
# -p Klmcargo2       → 密碼
# --users            → 列出所有網域使用者

# 關鍵輸出欄位：
# badpwdcount: 3  → 表示該帳號已有 3 次密碼錯誤
#                    密碼噴灑前應過濾掉 badPwdCount > 0 的帳號
#                    避免觸發鎖定
# baddpwdtime     → 最後一次密碼錯誤的時間
```

### 列舉網域群組

```bash
sudo crackmapexec smb 172.16.5.5 -u forend -p Klmcargo2 --groups
# --groups → 列出所有網域群組及每個群組的成員數（membercount）

# 高價值目標群組（立即記錄）：
# Administrators         → 本機管理員
# Domain Admins          → 網域管理員
# Backup Operators       → 可備份/還原檔案（繞過 NTFS 權限）
# Executives / Finance   → 可能持有高權 ACL
# Contractors            → 通常外包帳號，安全性較低
```

### 列舉已登入使用者（橫向移動前情報）

```bash
sudo crackmapexec smb 172.16.5.130 -u forend -p Klmcargo2 --loggedon-users
# 172.16.5.130      → 目標為檔案伺服器（非 DC）
# --loggedon-users  → 列出目前登入此主機的所有使用者

# 輸出欄位：
# INLANEFREIGHT\svc_qualys  logon_server: ACADEMY-EA-DC01
# → 發現 Domain Admin 帳號（svc_qualys）正在此機器上
# → 可考慮：記憶體竊取憑證 / Token 模擬

# (Pwn3d!) 出現 = forend 是 172.16.5.130 的本地管理員
# → 有 Admin$ 存取 = 可直接用 psexec / smbexec 拿 shell
```

### 列舉共用資料夾

```bash
sudo crackmapexec smb 172.16.5.5 -u forend -p Klmcargo2 --shares
# --shares → 列出所有共用資料夾及權限（READ / WRITE / NO ACCESS）

# 預設共用（通常有 READ）：
# IPC$     → 匿名/認證 RPC 通道
# NETLOGON → 登入腳本共用
# SYSVOL   → GPO 和登入腳本（GPP 密碼掃描目標）

# 非標準共用（重點調查）：
# Department Shares → 部門資料，可能含敏感資訊
# User Shares       → 使用者個人資料夾
# ZZZ_archive       → 封存資料，常有舊密碼/設定檔
```

### Spider_plus 模組（爬取共用資料夾）

```bash
sudo crackmapexec smb 172.16.5.5 -u forend -p Klmcargo2 \
  -M spider_plus --share 'Department Shares'
# -M spider_plus          → 載入 spider_plus 模組
# --share 'Department Shares' → 指定爬取的共用資料夾

# 輸出位置：/tmp/cme_spider_plus/<IP>.json
# 含每個可讀檔案的：atime / ctime / mtime / size

# 查看爬取結果
head -n 30 /tmp/cme_spider_plus/172.16.5.5.json
# 尋找高價值目標：
# *.bat / *.ps1  → 可能含硬編碼憑證
# web.config     → 應用程式資料庫密碼
# *.xml          → 設定檔
# *.txt          → 備忘密碼
```

## 工具二：SMBMap

### 理論

```text
SMBMap 專注於 SMB 共用資料夾的存取評估與內容探索。
特色：
  → 顯示每個共用的精確權限（READ ONLY / READ, WRITE / NO ACCESS）
  → 支援遞迴列目錄（-R）
  → 可搜尋檔案內容（--search）
  → 可下載 / 上傳檔案
  → 支援 NTLM hash 認證
```

```bash
# 基本用法：列出所有共用與權限
smbmap -u forend -p Klmcargo2 -d INLANEFREIGHT.LOCAL -H 172.16.5.5
# -u  → 使用者名稱
# -p  → 密碼
# -d  → 網域名稱（FQDN）
# -H  → 目標主機 IP

# 遞迴列出指定共用的所有目錄（只顯示目錄）
smbmap -u forend -p Klmcargo2 -d INLANEFREIGHT.LOCAL -H 172.16.5.5 \
  -R 'Department Shares' --dir-only
# -R 'Department Shares' → 遞迴列出 Department Shares 共用
# --dir-only             → 只顯示目錄（省略檔案列表，減少輸出雜訊）

# 遞迴列出（含檔案）
smbmap -u forend -p Klmcargo2 -d INLANEFREIGHT.LOCAL -H 172.16.5.5 \
  -R 'Department Shares'
# 不加 --dir-only → 同時列出檔案與目錄

# 下載特定檔案
smbmap -u forend -p Klmcargo2 -d INLANEFREIGHT.LOCAL -H 172.16.5.5 \
  --download 'Department Shares\IT\creds.txt'
# --download → 下載指定路徑的檔案到本地

# Pass-the-Hash 認證
smbmap -u forend -H 172.16.5.5 -p 'aad3b435b51404eeaad3b435b51404ee:NTLM_HASH'
# -p LM:NTLM 格式傳入 hash
```

## 工具三：rpcclient（有憑證）

### 理論

```text
rpcclient 是 Samba 套件提供的 MS-RPC 客戶端。
有憑證時可執行更多操作（vs. NULL session）：
  → 查詢使用者詳細屬性（包含 description 欄位）
  → 查詢群組成員
  → 查詢 SID → 名稱對應（RID cycling）
  → 建立 / 修改 / 刪除 AD 物件（若有相應權限）
```

```bash
# 有憑證連線（不提示輸入密碼）
rpcclient -U "INLANEFREIGHT.LOCAL\forend%Klmcargo2" 172.16.5.5
# -U "DOMAIN\user%password" → 網域使用者格式（用 % 分隔密碼）

# NULL session（若開放）
rpcclient -U "" -N 172.16.5.5
# -U "" → 空使用者名稱
# -N    → 不提示密碼

# 以下指令在 rpcclient 提示符下執行

rpcclient $> enumdomusers
# 列出所有網域使用者（含 RID）
# 輸出：user:[administrator] rid:[0x1f4]

rpcclient $> enumdomgroups
# 列出所有網域群組（含 RID）

rpcclient $> queryuser 0x1f4
# 查詢特定使用者詳細資訊（用 RID，十六進位）
# 輸出：Full Name / Description / Logon Count / Bad Password Count

rpcclient $> querygroup 0x200
# 查詢特定群組資訊

rpcclient $> querygroupmem 0x200
# 查詢群組成員（回傳 RID 列表）
# 再用 queryuser <RID> 查各成員詳情

rpcclient $> querydominfo
# 網域摘要：使用者數 / 群組數 / PDC Server Role 等

rpcclient $> getdompwinfo
# 密碼原則（最小長度 / 複雜度）

rpcclient $> lookupnames administrator
# 帳號名稱 → SID 對應
# 輸出：administrator S-1-5-21-...-500

rpcclient $> lookupsids S-1-5-21-3842939050-3880317879-2865463114-1164
# SID → 帳號名稱對應（RID cycling 核心）
```

```bash
# RID cycling（批次列舉，適合 enumdomusers 被封的情境）
for i in $(seq 500 1200); do
  rpcclient -U "forend%Klmcargo2" 172.16.5.5 \
    -c "lookupsids S-1-5-21-3842939050-3880317879-2865463114-$i" 2>/dev/null \
    | grep -v "NT_STATUS"
done
# S-1-5-21-...-$i → 替換 DOMAIN_SID 後循序枚舉每個 RID
# 原理：AD 每個帳號 RID 從 500（Administrator）起依序遞增
```

## 判斷邏輯

```
拿到低權憑證後
├── 確認有哪些主機（nxc smb 172.16.5.0/24）
├── 列使用者（--users）
│   └── 過濾 badPwdCount > 0 → 建立噴灑清單
├── 列群組（--groups）
│   └── 記錄高權群組：Domain Admins / Backup Operators / Executives
├── 列已登入使用者（--loggedon-users）
│   └── 發現高權帳號在線？→ 記錄主機 → 後續嘗試取得 shell / Token 模擬
├── 列共用資料夾（--shares）
│   ├── 非標準共用有 READ → SMBMap -R 遞迴列目錄
│   │   └── 找到可疑檔案 → --download 下載分析
│   └── SYSVOL 可讀 → 掃 GPP 密碼（見 73B 章）
├── spider_plus 掃全部可讀共用 → JSON 輸出分析
└── rpcclient 精細查詢
    ├── querygroupmem → 確認群組成員 RID
    ├── queryuser     → 讀取 description 欄位（常有密碼）
    └── RID cycling   → enumdomusers 被封時的替代方案
```

## 速查表

```bash
# CME - 使用者列舉
sudo crackmapexec smb DC_IP -u USER -p PASS --users

# CME - 群組列舉
sudo crackmapexec smb DC_IP -u USER -p PASS --groups

# CME - 已登入使用者
sudo crackmapexec smb TARGET_IP -u USER -p PASS --loggedon-users

# CME - 共用資料夾
sudo crackmapexec smb DC_IP -u USER -p PASS --shares

# CME - 爬取共用資料夾
sudo crackmapexec smb DC_IP -u USER -p PASS -M spider_plus --share 'SHARE_NAME'
cat /tmp/cme_spider_plus/DC_IP.json

# SMBMap - 列出共用權限
smbmap -u USER -p PASS -d DOMAIN.LOCAL -H DC_IP

# SMBMap - 遞迴列目錄
smbmap -u USER -p PASS -d DOMAIN.LOCAL -H DC_IP -R 'SHARE_NAME' --dir-only

# rpcclient - 有憑證連線
rpcclient -U "DOMAIN\USER%PASS" DC_IP

# rpcclient - 常用查詢
rpcclient $> enumdomusers
rpcclient $> querygroupmem 0x200
rpcclient $> queryuser 0x450
```
