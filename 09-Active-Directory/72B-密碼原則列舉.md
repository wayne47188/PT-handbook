## 學習目標

- 理解為何密碼原則是密碼噴灑前的必讀資訊。
- 能用 SMB NULL session（rpcclient / enum4linux-ng）無憑證取得密碼原則。
- 能用 LDAP 匿名繫結（ldapsearch）無憑證取得密碼原則。
- 能在 Windows 上用 net accounts / PowerView 取得密碼原則。
- 從原則數值判斷噴灑頻率與安全策略。

---

## 理論基礎

```text
為什麼要先拿密碼原則？
  密碼噴灑若鎖定帳戶 → 立刻暴露攻擊行為
  必須知道：
    鎖定閾值（Lockout Threshold）→ 最多能噴幾次
    鎖定持續時間（Lockout Duration）→ 被鎖後多久自動解鎖
    是否自動解鎖（vs. 需管理員手動解）
    最小密碼長度 → 決定候選密碼範圍
    密碼複雜度 → 是否需要大小寫+數字+特殊字元

取得管道（依認證需求）：
  無憑證：SMB NULL session / LDAP 匿名繫結
  有憑證：net accounts / PowerView / CrackMapExec

Windows 預設密碼原則（許多組織從未更改）：
  ┌───────────────────────┬──────────────────┐
  │ 原則項目              │ 預設值           │
  ├───────────────────────┼──────────────────┤
  │ 強制密碼歷程記錄      │ 24 次            │
  │ 最大密碼存在時間      │ 42 天            │
  │ 最小密碼存在時間      │ 1 天             │
  │ 最小密碼長度          │ 7 字元           │
  │ 密碼複雜度要求        │ 啟用             │
  │ 可逆式加密儲存        │ 停用             │
  │ 帳戶鎖定持續時間      │ 未設定           │
  │ 帳戶鎖定閾值          │ 0（不鎖定）      │
  │ 重設鎖定計數器        │ 未設定           │
  └───────────────────────┴──────────────────┘
```

## 方法一：SMB NULL Session（無憑證，Linux）

### 理論

```text
SMB NULL session = 空使用者名稱 + 空密碼連線
→ 舊版 DC 就地升級後遺留的不安全預設值
→ 允許匿名讀取：使用者清單、群組、密碼原則等

可用工具：rpcclient / enum4linux / enum4linux-ng
```

### rpcclient

```bash
# 測試 NULL session 是否開放
rpcclient -U "" -N 172.16.5.5
# -U "" → 空使用者名稱
# -N    → No password（不提示輸入密碼）

# 連入後查詢網域基本資訊
rpcclient $> querydominfo
# 輸出：Domain / Total Users / Server Role (ROLE_DOMAIN_PDC 確認是 DC)

# 取得密碼原則
rpcclient $> getdompwinfo
# min_password_length: 8          → 密碼長度下限
# password_properties: 0x00000001 → DOMAIN_PASSWORD_COMPLEX 已啟用
```

### enum4linux（舊版，Perl）

```bash
enum4linux -P 172.16.5.5
# -P → 只查 Password Policy

# 關鍵輸出欄位：
# Minimum password length: 8
# Account Lockout Threshold: 5
# Locked Account Duration: 30 minutes
# Reset Account Lockout Counter: 30 minutes
# Password Complexity Flags: 000001 → DOMAIN_PASSWORD_COMPLEX = 1

# enum4linux 使用的底層工具與連接埠：
# nmblookup   → 137/UDP
# nbtstat     → 137/UDP
# net         → 139/TCP, 135/TCP, 49152-65535
# rpcclient   → 135/TCP
# smbclient   → 445/TCP
```

### enum4linux-ng（新版，Python，推薦）

```bash
enum4linux-ng -P 172.16.5.5 -oA ilfreight
# -P    → 只查密碼原則（Password Policy）
# -oA   → 同時輸出 JSON 和 YAML（ilfreight.json / ilfreight.yaml）

# 輸出結構（YAML 格式）：
# domain_password_information:
#   min_pw_length: 8
#   pw_history_length: 24
#   min_pw_age: 1 day 4 minutes
#   max_pw_age: not set
#   pw_properties:
#   - DOMAIN_PASSWORD_COMPLEX: true
# domain_lockout_information:
#   lockout_threshold: 5
#   lockout_duration: 30 minutes
#   lockout_observation_window: 30 minutes
# domain_logoff_information:
#   force_logoff_time: not set

# 讀取輸出的 JSON 檔
cat ilfreight.json
# 可進一步用 jq 解析或傳給其他工具

# enum4linux-ng 優點（vs 舊版）：
# → Python 重寫，穩定性更高
# → -oA 輸出 JSON/YAML，利於自動化
# → 彩色輸出，可讀性高
# → 同時顯示 null session 是否成功的明確標記
```

## 方法二：LDAP 匿名繫結（無憑證，Linux）

### 理論

```text
LDAP 匿名繫結 = 不帶憑證的 LDAP 查詢
→ Windows Server 2003 之前的預設允許設定
→ 現代環境若仍開放，通常是為了某應用程式設定但誤給太大權限

可拿到：使用者/群組清單、密碼原則、帳戶屬性
```

```bash
# 用 ldapsearch 取得密碼原則相關屬性
ldapsearch -h 172.16.5.5 -x -b "DC=INLANEFREIGHT,DC=LOCAL" -s sub "*" \
  | grep -m 1 -B 10 pwdHistoryLength
# -h 172.16.5.5            → LDAP 伺服器 IP（新版用 -H ldap://IP）
# -x                       → 簡單認證（匿名）
# -b "DC=INLANEFREIGHT,DC=LOCAL" → 搜尋根 DN
# -s sub                   → scope = subtree（搜尋整棵樹）
# "*"                      → 查所有屬性
# grep -m 1 -B 10 pwdHistoryLength → 找到 pwdHistoryLength 並顯示前 10 行

# 關鍵輸出屬性：
# minPwdLength: 8          → 密碼長度下限
# pwdHistoryLength: 24     → 歷史密碼記錄筆數
# lockoutThreshold: 5      → 鎖定閾值
# lockoutDuration: -18000000000   → 負數 = 30 分鐘（Windows 100ns 單位）
# pwdProperties: 1         → 1 = 複雜度已啟用

# 注意：新版 ldapsearch 已棄用 -h，改用 -H
ldapsearch -H ldap://172.16.5.5 -x -b "DC=INLANEFREIGHT,DC=LOCAL" -s sub "*" \
  | grep -m 1 -B 10 pwdHistoryLength
```

## 方法三：Windows 主機（有憑證或本機）

### net accounts（內建，無需額外工具）

```cmd
net accounts
:: 輸出關鍵欄位：
:: Minimum password length:        8
:: Lockout threshold:              5
:: Lockout duration (minutes):     30
:: Lockout observation window:     30
:: Maximum password age (days):    Unlimited  ← 密碼永不過期！
```

### net use（Windows NULL session 測試）

```cmd
:: 建立 NULL session（測試是否開放）
net use \\DC01\ipc$ "" /u:""
:: "" /u:"" → 空密碼 / 空使用者名稱
:: 成功 → "The command completed successfully."

:: 常見錯誤碼（可用於帳號狀態判斷）：
:: 錯誤 1331 → System error 1331：帳戶已停用（account currently disabled）
net use \\DC01\ipc$ "" /u:guest

:: 錯誤 1326 → System error 1326：密碼錯誤（user name or password incorrect）
net use \\DC01\ipc$ "wrongpassword" /u:guest

:: 錯誤 1909 → System error 1909：帳戶已鎖定（account currently locked out）
net use \\DC01\ipc$ "password" /u:guest
```

### PowerView（有憑證環境）

```powershell
# 載入 PowerView
Import-Module .\PowerView.ps1

# 取得完整域原則
Get-DomainPolicy
# 輸出 SystemAccess 區段關鍵欄位：
# MinimumPasswordAge=1
# MaximumPasswordAge=-1       → -1 = 無限制（永不過期）
# MinimumPasswordLength=8
# PasswordComplexity=1        → 1 = 已啟用
# PasswordHistorySize=24
# LockoutBadCount=5           → 鎖定閾值
# ResetLockoutCount=30        → 重設計數器（分鐘）
# LockoutDuration=30          → 鎖定持續時間（分鐘）

# 輸出 KerberosPolicy 區段（對 Kerberos 攻擊有用）：
# MaxTicketAge=10     → TGT 最長有效時間（小時）
# MaxRenewAge=7       → TGT 最長可續期（天）
# MaxClockSkew=5      → 時間偏差容忍（分鐘）
```

## 解讀密碼原則：噴灑策略判斷

```text
INLANEFREIGHT.LOCAL 範例原則分析：
  最小密碼長度：8  → 可試 Welcome1, Password1, Company2024!
  鎖定閾值：5      → 每輪最多噴 3 次（保留 2 次緩衝）
  鎖定持續：30 分  → 等 31 分鐘再噴下一輪
  自動解鎖：是     → 不需管理員介入
  複雜度：啟用     → 密碼需含大小寫+數字（或特殊字元）

安全噴灑節奏：
  ┌─────────────────────────────────────────────┐
  │ 每輪噴灑 2-3 個密碼 → 等 31 分鐘 → 下一輪  │
  │ 鎖定閾值=3 的環境 → 每輪只噴 1 個          │
  │ 管理員手動解鎖環境 → 只噴 1 次，極度謹慎   │
  └─────────────────────────────────────────────┘

無法取得密碼原則時的保守策略：
  → 只噴一次，最多兩次（間隔 > 1 小時）
  → 或直接向客戶詢問原則（部分評估允許）
  → 絕不冒險鎖定帳戶（尤其管理員帳號）
```

## 判斷邏輯

```
需要密碼原則
├── 無憑證（Linux 上）
│   ├── 445 開放 → rpcclient -U "" -N → getdompwinfo
│   │              enum4linux-ng -P -oA
│   └── 389 開放 → ldapsearch -x -b "DC=..." → grep pwdHistoryLength
├── 有 Windows 主機（無需額外工具）
│   └── net accounts（cmd）
├── 有憑證（Windows + PowerView）
│   └── Get-DomainPolicy → SystemAccess 區段
└── 什麼都拿不到
    └── 假設最嚴格原則，只噴 1-2 次，間隔 > 60 分鐘
```
