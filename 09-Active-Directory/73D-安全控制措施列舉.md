## 學習目標

- 理解為何列舉安全控制措施是後滲透的必要前置步驟。
- 用 Get-MpComputerStatus 確認 Windows Defender 即時防護狀態。
- 用 Get-AppLockerPolicy 讀取 AppLocker 規則並找出封鎖/允許的路徑。
- 用 $ExecutionContext 確認 PowerShell 語言模式是否受限。
- 用 LAPSToolkit 列舉哪些 OU / 群組可讀取 LAPS 密碼。

---

## 理論基礎

```text
為何要列舉安全控制措施？
  → 工具選擇依賴於現有防護環境
  → Defender 啟用 → PowerView 被封 → 需混淆或替代工具
  → AppLocker 封 PowerShell → 改用其他 PS 可執行檔路徑
  → CLM（限制語言模式）→ 無法執行部分腳本類別
  → LAPS 部署 → 本機 Admin 密碼隨機，無法橫向複用

常見控制措施（由低到高嚴格度）：
  ┌────────────────────────────────────────────────────────┐
  │ 工具/原則             │ 影響                           │
  ├────────────────────────────────────────────────────────┤
  │ Windows Defender      │ 封鎖 PowerView 等工具          │
  │ AppLocker             │ 限制可執行的程式/腳本路徑      │
  │ PS Constrained LM     │ 禁止 COM、.NET、類別定義       │
  │ LAPS                  │ 本機 Admin 密碼自動輪替        │
  └────────────────────────────────────────────────────────┘

注意：本章聚焦於「列舉」，繞過方法見其他專屬模組。
```

---

## 一、Windows Defender

### 理論

```text
Windows Defender（Windows 10 2020/05 更新後改稱 Microsoft Defender）
  → 預設封鎖 PowerView 等已知攻擊工具
  → 關鍵欄位：RealTimeProtectionEnabled = True → 即時防護啟用
  → 關鍵欄位：AMServiceEnabled = True → 防毒服務啟用

Get-MpComputerStatus 是內建 PowerShell cmdlet，不需額外工具。
```

```powershell
Get-MpComputerStatus
# 回傳 Defender 完整狀態物件

# 關鍵欄位判讀：
# RealTimeProtectionEnabled : True   → 即時防護啟用，工具可能被攔截
# AMServiceEnabled          : True   → AV 服務正在運作
# AntivirusEnabled          : True   → 病毒掃描功能啟用
# BehaviorMonitorEnabled    : False  → 行為監控未啟用（較寬鬆）
# NISEnabled                : False  → 網路檢查系統未啟用

# 快速只看關鍵欄位
Get-MpComputerStatus | Select-Object AMServiceEnabled, AntivirusEnabled,
  RealTimeProtectionEnabled, BehaviorMonitorEnabled
```

## 二、AppLocker

### 理論

```text
AppLocker = Microsoft 應用程式白名單解決方案
  → 控制可執行：EXE / 腳本 / MSI / DLL / 封裝應用程式
  → 常見封鎖目標：
      cmd.exe / powershell.exe（%SYSTEM32% 路徑）
      對特定目錄的寫入權限

繞過思路（本章只列舉，不執行）：
  → 組織常忘記封鎖 32 位元 PS 路徑：
      %SystemRoot%\SysWOW64\WindowsPowerShell\v1.0\powershell.exe
  → PowerShell_ISE.exe 也常被遺漏
  → 規則只封鎖特定路徑 → 從 Allow 路徑執行即可

Action 欄位意義：
  Deny  → 明確封鎖（目標群組 SID）
  Allow → 明確放行
```

```powershell
Get-AppLockerPolicy -Effective | Select-Object -ExpandProperty RuleCollections
# -Effective → 讀取目前生效的合併原則（本機 + GPO）
# -ExpandProperty RuleCollections → 展開所有規則集合

# 輸出欄位判讀：
# PathConditions → 規則套用的路徑（含萬用字元）
#   %SYSTEM32%\WINDOWSPOWERSHELL\V1.0\POWERSHELL.EXE → 封鎖標準 PS 路徑
#   %PROGRAMFILES%\*  → 允許 Program Files 下所有程式
#   %WINDIR%\*        → 允許 Windows 目錄下所有程式
#   *                 → Administrators 群組允許執行一切
#
# UserOrGroupSid：
#   S-1-5-21-...-513  → Domain Users（封鎖對象）
#   S-1-1-0           → Everyone（放行對象）
#   S-1-5-32-544      → Local Administrators（放行對象）
#
# Action: Deny / Allow → 對應封鎖或放行

# 只列出 Deny 規則（找封鎖點）
Get-AppLockerPolicy -Effective | Select-Object -ExpandProperty RuleCollections |
  Where-Object { $_.Action -eq "Deny" }
```

## 三、PowerShell 限制語言模式（CLM）

### 理論

```text
PowerShell Constrained Language Mode（CLM）
  → 封鎖功能：COM 物件 / 未核准的 .NET 類型 / XAML 工作流程 / PS 類別
  → 常與 AppLocker 或 WDAC（Windows Defender Application Control）搭配
  → 在 CLM 下許多攻擊腳本（如 PowerView 進階功能）無法運作

語言模式值：
  FullLanguage        → 無限制，預設狀態
  ConstrainedLanguage → 受限，許多功能被封
  RestrictedLanguage  → 更嚴格，基本上只能讀取
  NoLanguage          → 完全不允許腳本
```

```powershell
$ExecutionContext.SessionState.LanguageMode
# 輸出值：
#   FullLanguage        → 無限制，工具可正常運作
#   ConstrainedLanguage → 受限模式，需調整策略
```

## 四、LAPS（本機系統管理員密碼解決方案）

### 理論

```text
LAPS（Local Administrator Password Solution）
  → 隨機化並輪替 Windows 主機的本機 Admin 密碼
  → 防止本機 Admin 密碼複用造成的橫向移動
  → 密碼儲存於 AD 電腦物件屬性（ms-Mcs-AdmPwd）
  → 只有被委派的群組/使用者才能讀取該屬性

關鍵列舉目標：
  1. 哪些 OU 已啟用 LAPS？哪些 OU 尚未部署？
  2. 哪些群組被委派讀取 LAPS 密碼？
  3. 哪些使用者擁有 All Extended Rights（可讀密碼）？
  4. 哪些電腦的 LAPS 密碼即將到期？

工具：LAPSToolkit（PowerShell 模組）
  → Find-LAPSDelegatedGroups   → 列舉被委派的群組（by OU）
  → Find-AdmPwdExtendedRights  → 找出擁有 All Extended Rights 的使用者
  → Get-LAPSComputers          → 列出電腦名稱 / 密碼 / 到期時間
```

### Find-LAPSDelegatedGroups（委派群組 by OU）

```powershell
Find-LAPSDelegatedGroups
# 列出每個 OU 被委派讀取 LAPS 密碼的群組

# 輸出欄位：
# OrgUnit          → 套用委派的 OU（LDAP DN 格式）
# Delegated Groups → 被委派的群組名稱

# 重點：LAPS Admins 群組的成員可讀取該 OU 內所有主機的本機 Admin 密碼
# → 若能控制 LAPS Admins 群組成員，可橫向至所有受管主機
```

### Find-AdmPwdExtendedRights（All Extended Rights 使用者）

```powershell
Find-AdmPwdExtendedRights
# 列出每台啟用 LAPS 的電腦上，擁有 All Extended Rights 的群組/使用者

# 輸出欄位：
# ComputerName → 目標電腦 FQDN
# Identity     → 群組或使用者
# Reason       → Delegated（被委派）

# 重點：
# 將電腦加入網域的帳號會自動獲得 All Extended Rights
# → 這類帳號保護通常較低，是高價值攻擊目標
# → 取得此類帳號 → 可讀取其加域電腦的 LAPS 密碼
```

### Get-LAPSComputers（電腦密碼與到期時間）

```powershell
Get-LAPSComputers
# 列出啟用 LAPS 的電腦及其密碼到期時間
# 若當前使用者有讀取權限 → 顯示明文密碼

# 輸出欄位：
# ComputerName → 電腦 FQDN
# Password     → 明文本機 Admin 密碼（有讀取權限時）
# Expiration   → 密碼到期時間

# 密碼欄位有值 → 當前帳號有讀取該電腦 LAPS 密碼的權限
# 密碼欄位空白 → 無權限，或該電腦未啟用 LAPS
```

## 判斷邏輯

```
取得 Windows 據點後 → 列舉安全控制措施
├── Defender 狀態
│   └── Get-MpComputerStatus
│       ├── RealTimeProtectionEnabled = True
│       │   → 避免直接執行已知工具（PowerView 等）
│       │   → 改用混淆版本 / 記憶體載入 / 替代工具
│       └── RealTimeProtectionEnabled = False
│           → 防護未啟用，工具可直接使用
│
├── AppLocker 規則
│   └── Get-AppLockerPolicy -Effective | ... RuleCollections
│       ├── 發現 Deny 規則封鎖 %SYSTEM32%\...powershell.exe
│       │   → 改用 SysWOW64 路徑或 PowerShell_ISE.exe
│       └── 無 Deny 規則 → 無路徑限制
│
├── PowerShell 語言模式
│   └── $ExecutionContext.SessionState.LanguageMode
│       ├── ConstrainedLanguage → 腳本功能受限
│       │   → 改用編譯後的 .NET 工具（SharpView 等）
│       └── FullLanguage → 無限制
│
└── LAPS 部署
    ├── Find-LAPSDelegatedGroups → 確認哪些 OU 有 LAPS
    ├── Find-AdmPwdExtendedRights → 找加域帳號（高價值目標）
    └── Get-LAPSComputers
        ├── 有密碼 → 可直接用本機 Admin 登入目標
        └── 無密碼（無讀取權限）→ 先拿 LAPS Admins 群組成員帳號
```

## 速查表

```powershell
# Defender 狀態
Get-MpComputerStatus | Select-Object AMServiceEnabled, AntivirusEnabled,
  RealTimeProtectionEnabled, BehaviorMonitorEnabled

# AppLocker 規則（所有）
Get-AppLockerPolicy -Effective | Select-Object -ExpandProperty RuleCollections

# AppLocker Deny 規則（快速看封鎖點）
Get-AppLockerPolicy -Effective | Select-Object -ExpandProperty RuleCollections |
  Where-Object { $_.Action -eq "Deny" }

# PowerShell 語言模式
$ExecutionContext.SessionState.LanguageMode

# LAPS - 委派群組（by OU）
Find-LAPSDelegatedGroups

# LAPS - All Extended Rights 使用者
Find-AdmPwdExtendedRights

# LAPS - 電腦密碼與到期時間
Get-LAPSComputers

# PS 備用路徑（AppLocker 封鎖 SYSTEM32 時）
%SystemRoot%\SysWOW64\WindowsPowerShell\v1.0\powershell.exe
```
