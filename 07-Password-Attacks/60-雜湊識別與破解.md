## 學習目標

- 能識別常見雜湊格式（NTLM、SHA、bcrypt、MD5 等）。
- 知道 hashcat 各模式（-m）對應的 hash 類型。
- 能用字典、規則、遮罩三種策略組合破解雜湊。
- 理解 salt、iteration 對破解難度的影響。
- 能把 john 與 hashcat 按場景選用。

---

## 理論基礎：破解難度決定因素

| 因素 | 影響 | 說明 |
|------|------|------|
| 算法速度 | 高速 = 易破解 | MD5/NTLM 每秒可試數十億次；bcrypt 每秒數千次 |
| Salt | 防彩虹表 | 加 salt 後需逐一計算，不能用預計算表 |
| Iteration/Cost Factor | 慢雜湊 | bcrypt/PBKDF2 刻意增加計算量 |
| 密碼複雜度 | 候選空間 | 長度+字符集組合決定搜索空間 |
| 字典品質 | 命中率 | 針對目標的字典命中率遠高於通用字典 |

**核心原則**：先辨識格式 → 再選策略 → 字典先、遮罩後。

## 方法一：雜湊識別

```bash
# 工具 1：hashid（推薦，支援更多格式）
pip install hashid
hashid '$apr1$xyz$...'
# 輸出：[+] MD5(APR) [+] Apache MD5
# 說明：從格式特徵（前綴、長度、字符集）推測可能類型

# 工具 2：hash-identifier（互動式）
hash-identifier
# 貼入 hash → 列出可能類型

# 工具 3：name-that-hash（更現代，彩色輸出）
pip install name-that-hash
nth --text '$2y$10$...'
# 輸出排序：最可能的格式在最前面

# 手動識別特徵
# $1$...  → MD5crypt（Linux /etc/shadow 舊格式）
# $2y$... → bcrypt
# $5$...  → SHA-256crypt（Linux 現代格式）
# $6$...  → SHA-512crypt（Linux 最常見）
# 32 hex chars → MD5 或 NTLM（看來源）
# 40 hex chars → SHA-1
# 64 hex chars → SHA-256
# 128 hex chars → SHA-512
```

## 常用 hashcat -m 模式對照表

| -m 值 | 類型 | 常見來源 | 破解速度 |
|-------|------|----------|----------|
| 0 | MD5 | 舊系統、資料庫 | 極快 |
| 100 | SHA-1 | Git、舊 web | 極快 |
| 1000 | NTLM | Windows SAM、LSASS | 極快 |
| 1800 | sha512crypt ($6$) | Linux /etc/shadow | 慢 |
| 3200 | bcrypt ($2*$) | Web 框架 | 極慢 |
| 500 | md5crypt ($1$) | Linux 舊 shadow | 慢 |
| 1500 | DES (descrypt) | 舊 Unix | 快 |
| 5600 | NetNTLMv2 | Responder 捕獲 | 快 |
| 5500 | NetNTLMv1 | Responder 捕獲 | 快 |
| 13100 | Kerberos 5 TGS (RC4) | Kerberoasting | 快 |
| 18200 | Kerberos 5 AS-REP (RC4) | AS-REP Roasting | 快 |
| 2500 | WPA-PBKDF2-PMKID | 無線網路 | 很慢 |
| 400 | WordPress ($P$) | WordPress 資料庫 | 慢 |

```bash
# 確認 -m 模式（不確定時用 hashid 或直接試）
hashcat -m 1000 hash.txt /usr/share/wordlists/rockyou.txt
# -m 1000 → NTLM 模式
# hash.txt → 一行一個 hash
```

## 方法二：hashcat 字典攻擊

```bash
# 基本字典攻擊（-a 0）
hashcat -m 1000 -a 0 hashes.txt /usr/share/wordlists/rockyou.txt
# -m 1000 → NTLM
# -a 0    → 字典模式（Straight mode）
# hashes.txt → 目標 hash 清單
# rockyou.txt → 字典

# 加速選項
hashcat -m 1000 -a 0 hashes.txt rockyou.txt --force -O
# --force → 忽略警告（GPU 驅動問題時）
# -O      → 優化核心（速度快但密碼長度有限）

# 顯示破解進度
hashcat -m 1000 -a 0 hashes.txt rockyou.txt --status --status-timer=10
# --status       → 顯示進度
# --status-timer → 每 10 秒更新一次

# 查看已破解的結果
hashcat -m 1000 hashes.txt --show
# --show → 從 hashcat.potfile 顯示已破解結果
# potfile 預設位置：~/.hashcat/hashcat.potfile

# 輸出到檔案
hashcat -m 1000 -a 0 hashes.txt rockyou.txt -o cracked.txt
# -o → 輸出格式：hash:plaintext
```

## 方法三：規則攻擊（字典 + 變形）

```bash
# 查看可用規則
ls /usr/share/hashcat/rules/
# best64.rule        → 64 種最有效變形（推薦入手）
# rockyou-30000.rule → 3 萬種規則（全面但慢）
# d3ad0ne.rule       → 激進版
# Hob0Rules/         → 各種組合規則集

# 套用規則攻擊（-a 0 + -r）
hashcat -m 1000 -a 0 hashes.txt rockyou.txt -r /usr/share/hashcat/rules/best64.rule
# -r → 指定規則檔案
# 規則在字典每個詞上套用所有變形（如首字母大寫、加數字後綴）

# 預覽規則效果（不實際破解）
hashcat --stdout -r /usr/share/hashcat/rules/best64.rule wordlist.txt | head -50
# --stdout → 只輸出候選，不做 hash 運算

# 堆疊多個規則
hashcat -m 1000 -a 0 hashes.txt rockyou.txt \
  -r /usr/share/hashcat/rules/best64.rule \
  -r /usr/share/hashcat/rules/toggles1.rule
# 可以疊加多個 -r（順序套用）

# 常用規則邏輯（部分 best64.rule 解說）
# l → 全小寫 (password)
# u → 全大寫 (PASSWORD)
# c → 首字母大寫 (Password)
# $1 → 附加 "1" (password1)
# $! → 附加 "!" (password!)
# ^1 → 前綴加 "1" (1password)
```

## 方法四：遮罩攻擊（已知格式時用）

```bash
# 遮罩字符集
# ?l → 小寫字母 a-z
# ?u → 大寫字母 A-Z
# ?d → 數字 0-9
# ?s → 特殊字符 !@#... 等
# ?a → 全部字符（?l+?u+?d+?s）

# 基本遮罩攻擊（-a 3）
hashcat -m 1000 -a 3 hashes.txt ?u?l?l?l?l?l?d?d
# -a 3   → 遮罩模式（Brute-force）
# ?u?l?l?l?l?l?d?d → 8 位：1 大寫 + 5 小寫 + 2 數字（如 Password01）

# 常見企業密碼模式
hashcat -m 1000 -a 3 hashes.txt ?u?l?l?l?l?d?d?d?s
# 如 Summer23! 的格式：大+小*4+數*3+符號

# 季節+年份模式（針對企業環境）
hashcat -m 1000 -a 0 hashes.txt seasons.txt -r year_suffix.rule
# 先建一個包含 Spring/Summer/Autumn/Winter 的 seasons.txt
# 配合規則加年份後綴

# 混合模式（-a 6/-a 7）
hashcat -m 1000 -a 6 hashes.txt rockyou.txt ?d?d?d?d
# -a 6 → 字典 + 遮罩（後綴）：把字典每個詞加上 4 位數字
hashcat -m 1000 -a 7 hashes.txt ?d?d?d?d rockyou.txt
# -a 7 → 遮罩 + 字典（前綴）：4 位數字加在字典詞前面
```

## 方法五：john the Ripper

```bash
# john 的優勢：自動識別格式、處理特殊格式（/etc/shadow、zip/ssh key 等）

# 自動識別並破解（john 會猜格式）
john hashes.txt
# 自動偵測並套用 wordlist + mangling rules

# 指定 wordlist
john hashes.txt --wordlist=/usr/share/wordlists/rockyou.txt
# --wordlist → 指定字典

# 指定格式（不確定時用 --list=formats 查看）
john hashes.txt --format=NT --wordlist=rockyou.txt
# --format=NT → NTLM
# --format=sha512crypt → Linux $6$ hash
# --format=bcrypt → bcrypt

# 查看所有支援格式
john --list=formats | grep -i ntlm
john --list=formats | grep -i bcrypt

# 顯示已破解結果
john hashes.txt --show

# 特殊格式處理工具（john 提供轉換腳本）
# SSH 私鑰
ssh2john id_rsa > id_rsa.hash
john id_rsa.hash --wordlist=rockyou.txt

# zip 壓縮檔密碼
zip2john secret.zip > zip.hash
john zip.hash --wordlist=rockyou.txt

# /etc/shadow（需先合併 passwd + shadow）
unshadow /etc/passwd /etc/shadow > shadow.hash
john shadow.hash --wordlist=rockyou.txt
# unshadow → 合併兩個檔案為 john 可讀格式
```

## 破解策略決策流程

```
取得 hash
    ↓
1. 識別格式（hashid / nth / 前綴特徵）
    ↓
2. 判斷速度
    ├─ 快速（MD5/NTLM/SHA1）→ 全字典 + 規則
    └─ 慢速（bcrypt/sha512crypt）→ 精準字典優先
    ↓
3. 選字典
    ├─ 通用：rockyou.txt（1400萬）
    ├─ 快速：top-10000.txt（10分鐘內出結果）
    └─ 針對目標：cewl 爬站 + 組織名/季節/年份
    ↓
4. 套規則（best64.rule）
    ↓
5. 若無命中 → 遮罩攻擊（已知格式規律）
    ↓
6. 破解成功 → 記錄帳號+密碼+後續重用評估
```

## 速查表

```bash
# 識別格式
hashid 'HASH_STRING'
nth --text 'HASH_STRING'

# NTLM 字典破解
hashcat -m 1000 -a 0 hashes.txt /usr/share/wordlists/rockyou.txt

# NTLM 字典 + 規則
hashcat -m 1000 -a 0 hashes.txt rockyou.txt -r /usr/share/hashcat/rules/best64.rule

# Linux shadow ($6$) 破解
hashcat -m 1800 -a 0 shadow.hash rockyou.txt -r best64.rule

# NetNTLMv2（Responder 捕獲）
hashcat -m 5600 -a 0 netntlm.hash rockyou.txt

# Kerberoasting hash
hashcat -m 13100 -a 0 kerb.hash rockyou.txt

# AS-REP Roasting hash
hashcat -m 18200 -a 0 asrep.hash rockyou.txt

# SSH 私鑰密碼
ssh2john id_rsa > id_rsa.hash && john id_rsa.hash --wordlist=rockyou.txt

# 查看結果
hashcat -m 1000 hashes.txt --show
john hashes.txt --show
```
