# Sliver — 基礎概念

## 什麼是 Sliver？

BishopFox 開發的開源 C2 框架，以 Go 語言編寫，跨平台（Windows / Linux / macOS）。

**主要特點：**
- 支援 mTLS、WireGuard、HTTP/S、DNS、Named Pipe、TCP 等傳輸協議
- 兩種 Implant 模式：Session（互動）與 Beacon（異步）
- 內建 SOCKS5、Port Forwarding、Process Injection
- 支援 BOF 與 .NET Assembly 執行
- 多操作員（Multiplayer）支援

---

## 核心術語

| 術語 | 說明 |
|------|------|
| **Server** | Sliver 服務端，管理所有連線與 Implant |
| **Operator** | 連接到 Server 的操作者 |
| **Implant** | 在目標主機執行的惡意程式（Beacon 或 Session）|
| **Listener / Job** | Server 端等待 Implant 回連的服務 |
| **Beacon** | 異步模式 Implant，定期回連執行任務 |
| **Session** | 互動模式 Implant，即時雙向通訊 |
| **Profile** | 保存的 Implant 生成參數設定檔 |
| **Armory** | 延伸套件管理器 |
| **Stager** | 小型下載器，下載並執行 Stage 2 |

## 架構

```
┌─────────────┐         ┌──────────────┐
│  Operator   │  mTLS   │    Sliver    │
│  (Client)   │◄───────►│    Server    │
└─────────────┘         └──────┬───────┘
                               │  Listeners
                    ┌──────────┼──────────┐
                    │          │          │
               mTLS/HTTP    WireGuard   DNS
                    │          │          │
               ┌────▼──────────▼──────────▼────┐
               │         Target Network         │
               │   ┌─────────┐  ┌─────────┐    │
               │   │ Beacon  │  │ Session │    │
               │   └─────────┘  └─────────┘    │
               └────────────────────────────────┘
```

**流程：**
1. Server 啟動 Listener（如 mTLS :4444）
2. Implant 執行後主動回連 Server
3. Operator 透過 Client 連接 Server
4. Operator 對 Session/Beacon 下指令，Server 轉發給 Implant

## Beacon vs Session

| 特性 | Beacon | Session |
|------|--------|---------|
| **通訊方式** | 定期輪詢（Pull）| 即時連線（Push）|
| **互動性** | 異步，等待下次 Checkin | 即時互動 |
| **OPSEC** | 較佳（流量間歇）| 較差（持續連線）|
| **適用場景** | 長期潛伏、橫向移動 | 快速偵察 |
| **Sleep 設定** | 可設定 sleep + jitter | 不適用 |
| **查看回應** | `tasks fetch` | 立即顯示 |

> **顏色辨識**：Session 名稱顯示為 🔴 紅色，Beacon 為 🔵 藍色

**建議策略：**
- 初始存取 → 用 Session（需要快速偵察）
- 立足點建立後 → 轉 Beacon（降低偵測風險）
- 用 `interactive` 將 Beacon 暫時轉為 Session

## Server 與 Client 的關係

### 角色定義

```
┌─────────────────────────────────────────────┐
│               Sliver Server                 │
│  - 管理所有 Listeners（Jobs）                │
│  - 儲存 Implant 憑證與 PKI                  │
│  - 轉發 Operator 指令給 Implant             │
│  - 維護 Session / Beacon 狀態               │
└───────────────┬─────────────────────────────┘
                │  mTLS（Operator 連線）
    ┌───────────┴────────────┐
    │                        │
┌───▼──────────┐   ┌────────▼─────────┐
│  Operator A  │   │   Operator B     │
│  (Client)    │   │   (Client)       │
│ sliver-client│   │  sliver-client   │
└──────────────┘   └──────────────────┘
```

### 重要概念

**Server 是核心、Client 是終端**

- **Server** 持續在背景執行，維護所有 Listener、Session、Beacon 狀態
- **Client（Operator）** 是操作介面，連接 Server 後才能下指令
- Client 斷線後，Server 與 Implant 之間的連線**仍然維持**
- 多個 Client 可同時連接同一台 Server（Multiplayer 模式）

### Client 連接機制

Server 和 Client 之間使用 **mTLS 雙向驗證**：

```bash
# Server 端：生成 Operator 設定檔（含憑證）
sliver-server > multiplayer new-operator --name wayne --lhost 10.10.14.62

# 會產生 wayne.cfg（包含 Server 位址、CA、Client 憑證）
# 將 wayne.cfg 傳給對應的 Operator

# Client 端：匯入設定檔並連線
sliver import wayne.cfg
sliver   # 連線到 Server
```

### 本機模式 vs 遠端模式

| 模式 | 說明 | 使用時機 |
|------|------|---------|
| **本機模式** | `sliver-server` 啟動後直接在本機使用 | 單人操作、測試 |
| **遠端模式** | Server 跑在遠端，Client 透過 `.cfg` 連入 | 多人協作、Team Server |

```bash
# 本機模式：直接執行 server 即可操作
sudo sliver-server

# 遠端模式：Server 開啟 Multiplayer，Client 用 .cfg 連入
# Server 端
sliver-server > multiplayer         # 啟用 Multiplayer 模式
sliver-server > new-operator --name alice --lhost <SERVER_IP>

# Client 端
sliver import alice.cfg
sliver
```

### 指令執行流程

```
Operator 輸入指令
      ↓
Client 透過 mTLS 傳送給 Server
      ↓
Server 將指令封裝後透過 Listener 傳給 Implant
      ↓
Implant 執行並回傳結果
      ↓
Server 解封裝後回傳給 Client（Operator 看到輸出）
```

**Beacon 的差異：**
```
Operator 輸入指令 → Server 儲存為「待執行任務」
      ↓（等待 Beacon 下次 Checkin）
Beacon 主動回連 Server → 取得任務執行 → 回傳結果
      ↓
Operator 執行 tasks fetch 取得結果
```

### 常用 Client 管理指令

```bash
operators                              # 列出目前連線的 Operators
kick-operator --name alice             # 踢出 Operator
multiplayer new-operator --name bob --lhost <IP>  # 新增 Operator
```

## 傳輸協議比較

| 協議 | 預設 Port | OPSEC | 穿透力 | 備註 |
|------|-----------|-------|--------|------|
| **mTLS** | 4444 | 中 | 中 | 雙向憑證驗證，預設推薦 |
| **HTTPS** | 443 | 高 | 高 | 融入正常流量，建議首選 |
| **HTTP** | 80 | 低 | 高 | 明文，不建議 |
| **DNS** | 53 | 高 | 最高 | 速度慢，極端環境用 |
| **WireGuard** | 53 | 中 | 中 | VPN 隧道 |
| **Named Pipe** | — | 高 | 內網限定 | Windows 橫向移動 |
| **TCP** | 8888 | 低 | 低 | 直連，測試用 |
