## 學習目標

- 建立系統性的 Linux 本機提權枚舉順序。
- 找出系統中的敏感檔案、設定與憑證。
- 識別高權服務、進程與排程工作。
- 確認安裝的套件版本，找到可利用的舊版元件。

---

## 理論基礎：枚舉的目標

進入 Linux 機器後，枚舉的優先順序：

| 優先級 | 類別 | 為什麼 |
|--------|------|--------|
| 1 | sudo / SUID / caps | 最快速、最穩定的提權路線 |
| 2 | 可寫高權腳本 / cron | 執行鏈控制 → 直接 root |
| 3 | 憑證 / SSH key / 設定檔 | 密碼重用 → su / SSH |
| 4 | 服務版本 / 套件 | 已知 CVE |
| 5 | 核心版本 | 最後手段 |

## 方法一：系統基本資訊

```bash
# OS 和核心版本
uname -a
# 輸出：Linux hostname 5.4.0-74-generic #83-Ubuntu SMP...
# uname → 系統資訊
# -a    → 全部資訊（核心版本/架構/發行版）

cat /etc/os-release
# 發行版名稱、版本
# 用途：判斷可用的 exploit / 服務版本

cat /proc/version
# 核心版本（另一個來源）

# 主機名稱 → 判斷角色
hostname
# web01 / db01 / dev / dc → 調整策略

# CPU 架構（exploit 要配對）
arch
# x86_64 / i686 / aarch64

# 已安裝套件（找舊版漏洞）
dpkg -l 2>/dev/null | head -50
# dpkg → Debian/Ubuntu 套件管理
# -l   → 列出已安裝套件（名稱/版本/描述）

rpm -qa 2>/dev/null | head -50
# rpm → RedHat/CentOS 套件管理
# -q  → 查詢
# -a  → 全部套件

# 磁碟掛載（找 NFS、額外分區）
cat /etc/fstab
# 列出所有掛載點設定
# 找 nfs / nosuid / noexec 等選項

mount | grep -v "proc\|sysfs\|devpts\|tmpfs\|cgroup"
# 列出當前掛載，排除虛擬系統
```

## 方法二：使用者、群組與登入記錄

```bash
# 當前身份
id
# uid/gid/groups 全部顯示

# 所有帳號
cat /etc/passwd
# 格式：user:x:UID:GID:comment:home:shell
# x → 密碼在 /etc/shadow 中

# 有 login shell 的帳號（可能是真人帳號）
grep -v "nologin\|false\|sync\|halt\|shutdown" /etc/passwd
# grep -v → 反向過濾（排除這些 shell）

# 所有群組定義
cat /etc/group
# 格式：groupname:x:GID:members

# 高價值群組成員
grep -E "^(sudo|docker|lxd|disk|shadow|adm|wheel)" /etc/group
# ^ → 開頭匹配（群組名稱在第一欄）

# 最近登入的使用者
last
# 輸出：使用者名稱 / 來源 IP / 登入時間
# last -20 → 只看最近 20 筆

lastlog
# 所有帳號最後登入時間

# 當前在線使用者
w
# 輸出：使用者/登入時間/來源 IP/當前執行的指令

# 查看其他使用者的家目錄
ls -la /home/
# 確認是否可讀（可能直接找到 key/設定檔）

# 讀其他使用者的 bash history（若可讀）
cat /home/*/.*history 2>/dev/null
cat ~/.bash_history
# .bash_history → bash 指令歷史
# .zsh_history  → zsh 指令歷史
# 找密碼/指令使用模式
```

## 方法三：進程與服務

```bash
# 列出所有執行中的進程（看 root 執行了什麼）
ps aux
# a → 所有使用者的進程
# u → 以使用者格式顯示
# x → 包含沒有 tty 的進程（背景進程）
# 重點：USER=root 的服務名稱和執行路徑

# 精簡版（只看 root 進程）
ps aux | grep "^root"
# ^root → USER 欄開頭是 root 的行

# 進程樹（看父子關係）
pstree -a
# -a → 顯示完整指令（含參數）

# 服務狀態（systemd）
systemctl list-units --type=service --state=running
# list-units → 列出服務
# --type=service → 只看 service
# --state=running → 只看執行中的

# 查看特定服務的設定（找執行帳號/路徑）
systemctl cat SERVICE_NAME
# 輸出：ExecStart= / User= / WorkingDirectory=

# 監聽的 port（找內部服務）
ss -tlnp
# -t → TCP
# -l → LISTEN 狀態
# -n → 數字顯示
# -p → 程序名稱

# 配合 curl 測試本機服務
curl http://127.0.0.1:PORT 2>/dev/null
# 找只監聽 127.0.0.1 的 Web 服務（可能有未授權存取）
```

## 方法四：敏感檔案搜尋

```bash
# ─────── SSH 金鑰 ───────
find /home /root /etc /var -name "id_rsa" -o -name "id_ecdsa" -o -name "*.pem" 2>/dev/null
# -name → 符合檔案名稱
# -o    → OR（也找這個）

# 找 authorized_keys（知道誰可以 SSH 進來）
find /home /root -name "authorized_keys" 2>/dev/null

# ─────── 密碼相關 ───────
# 搜尋設定檔中的密碼
grep -rn "password\|passwd\|pwd\|secret" /var/www/ /opt/ /home/ /etc/ 2>/dev/null --include="*.conf" --include="*.config" --include="*.xml" --include="*.txt" | grep -v "Binary"
# -r          → 遞迴搜尋
# -n          → 顯示行號
# --include   → 只搜尋這些副檔名
# | grep -v "Binary" → 排除 binary 檔案的錯誤輸出

# Web 應用設定（資料庫連接字串）
find /var/www /var/html /srv -name "*.php" -o -name "*.conf" 2>/dev/null | xargs grep -l "password\|DB_PASS" 2>/dev/null
# xargs → 把 find 輸出作為 grep 的參數

# ─────── 重要設定檔位置 ───────
cat /etc/ssh/sshd_config
# PermitRootLogin yes → root 可直接 SSH
# PasswordAuthentication yes → 密碼登入開啟

cat /etc/sudoers 2>/dev/null
# 看完整 sudo 規則（需要讀取權限）
# NOPASSWD / 萬用字元 / 群組設定

cat /root/.bash_history 2>/dev/null
# root 的指令歷史（若可讀）

ls -la /root/ 2>/dev/null
# root 家目錄（若可讀）

# ─────── 備份與暫存 ───────
find / -name "*.bak" -o -name "*.backup" -o -name "*.old" 2>/dev/null
# 備份檔案 → 可能含舊版密碼

find /tmp /var/tmp /dev/shm -type f 2>/dev/null
# 暫存目錄 → 可能有 token/上傳的工具/歷史

# ─────── 環境變數 ───────
env
# 列出所有環境變數
# 找 AWS_SECRET / API_KEY / PASSWORD / DB_PASS

printenv
# 同上（另一個指令）
```

## 速查表

```bash
# 系統版本
uname -a && cat /etc/os-release

# 身份和群組
id && cat /etc/group | grep -E "sudo|docker|lxd|disk|shadow"

# 進程（root 執行了什麼）
ps aux | grep "^root"

# 網路監聽
ss -tlnp

# SSH key
find /home /root -name "id_rsa" 2>/dev/null

# 密碼搜尋
grep -rn "password" /var/www /opt /home 2>/dev/null --include="*.conf" --include="*.php"

# 歷史紀錄
cat ~/.bash_history && cat /home/*/.bash_history 2>/dev/null

# 套件版本
dpkg -l 2>/dev/null || rpm -qa 2>/dev/null
```
